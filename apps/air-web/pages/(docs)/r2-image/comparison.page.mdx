# Architecture & Cost Comparison

In cloud infrastructure, saving cost is conventionally assumed to require cutting corners on developer experience (DX) or end-user performance (UX). R2 Image fundamentally rejects this premise. Backed by Cloudflare R2 and Containers, **R2 Image** delivers **67% to 85% cost savings vs. Vercel** (up to ~92% regionally) and **11% to 64% savings vs. Cloudflare Hosted**, while bringing lower developer effort and faster client delivery than managed services:

| Dimension | The Industry Assumption | What R2 Image Delivers |
| :--- | :--- | :--- |
| **Cost** | Saving money requires complex self-hosted infrastructure or cutting quality. | **67% to 85% cheaper** via zero-egress R2/Workers and at-cost Cloudflare Containers. |
| **DX** | Cutting costs means managing SQS queues, Lambda timeouts, and storage glue code. | **Cleaner than SaaS**: 1 SDK upload call, clean POSIX paths in your own bucket, and zero database lock-in. |
| **UX** | Users download 2MB–8MB raw assets, waiting seconds on mobile and burning data caps. | **90%+ lighter downloads**: Fast edge-cached ~50 KB WebP payloads with instant visual paint and zero layout shifts. |

## Delivery Pipeline Benchmarks

An accurate financial comparison measures the complete delivery pipeline from end to end:
1. **Master Origin Storage**: Storing full-resolution original assets.
2. **Transformation Compute**: Resizing and re-encoding variants via CPU.
3. **Cache Storage & Operations**: Serving cached variants at the edge.
4. **Delivery Bandwidth (Egress)**: Transferring bytes to end-users globally.

The comparison evaluates four complete delivery architectures:
- **R2 Image (Full Pipeline)**: Cloudflare R2 Master Storage ($0.015/GB) + Containers Compute (`standard-2`, 1 TB included egress) + Workers/DO edge proxy + Cloudflare CDN Delivery (**$0.00 edge egress**).
- **Cloudflare Images (Hosted Full)**: Proprietary store ($5/100k stored) + Cloudflare CDN Delivery ($1/100k delivered).
- **Cloudflare Images (BYOS Full)**: R2 Master Storage ($0.015/GB) + Cloudflare Transformations ($0.50/1k) + Cloudflare CDN Delivery (**$0.00 edge egress**).

## Developer Experience

Code implementation required to upload, store, and present images across each architecture:

### Upload Implementation

Code and operational steps required to ingest source binaries and prepare variant pipelines:

#### R2 Image

Unified SDK upload with eager variants:

```ts [src/upload.ts]
import { upload } from '@irpclib/r2-image';

// Uploads directly to R2 and prepares responsive variants in a single pass
await upload('users/93/avatar.png', file, {
  sizes: [
    { name: 'thumbnail', width: 128, height: 128, format: 'webp' },
    { name: 'cover', size: 1024, format: 'webp' },
  ],
});
```
- **Code Footprint**: 1 function call.
- **Architecture**: Streams upload progress, persists assets to R2, and eagerly generates variants without background SQS queues or Lambda workers.
- **Database Stored**: Clean relative POSIX path (`users/93/avatar.png`).

#### Vercel

Decoupled storage and upload API route:

```ts [app/api/upload/route.ts]
import { put } from '@vercel/blob';

export async function POST(req: Request) {
  const form = await req.formData();
  const file = form.get('file') as File;
  const blob = await put(`users/93/${file.name}`, file, { access: 'public' });
  return Response.json(blob);
}
```

```tsx [src/UploadButton.tsx]
const formData = new FormData();
formData.append('file', file);
const res = await fetch('/api/upload', { method: 'POST', body: formData });
const { url } = await res.json(); // Full Vercel Blob URL
```
- **Code Footprint**: API route handler + client form submit logic.
- **Architecture**: Origin storage is decoupled from optimization. Variants are generated lazily on initial request cache misses.
- **Database Stored**: Full storage URLs.

#### Cloudflare Images

Direct creator token handshake via REST API:

```ts [src/upload-cf.ts]
// 1. Server requests one-time upload token via Cloudflare REST API
const cfRes = await fetch(
  `https://api.cloudflare.com/client/v4/accounts/${ACCOUNT_ID}/images/v2/direct_upload`,
  { method: 'POST', headers: { Authorization: `Bearer ${CF_API_TOKEN}` } }
);
const { result } = await cfRes.json();

// 2. Client uploads binary to Cloudflare proprietary store
const formData = new FormData();
formData.append('file', file);
const uploadRes = await fetch(result.uploadURL, { method: 'POST', body: formData });
const { result: imageResult } = await uploadRes.json();

// 3. Database stores proprietary vendor UUID
await db.users.update({ avatarId: imageResult.id }); // e.g. "b02d8f99-90bc-43cf-26e7-573516598500"
```
- **Code Footprint**: Multi-step REST handshake (token generation endpoint → client upload).
- **Architecture**: Enforces a strict 10 MB file ceiling; files reside in a proprietary store.
- **Database Stored**: Opaque vendor UUID (`b02d8f99...`), creating permanent database lock-in.

### Delivery Implementation

Component markup and client integration required to present responsive image assets:

#### R2 Image

Native HTML `<img>` with longest-edge sizing:

```html
<!-- Named preset declared in worker configuration -->
<img src="https://cdn.example.com/users/93/avatar.png?name=thumbnail" alt="Avatar" />

<!-- Dynamic orientation-agnostic cap on the longest edge -->
<img src="https://cdn.example.com/photos/vacation.jpg?s=640&f=webp" alt="Vacation" />
```

Programmatic generation via the `url()` helper:

```ts
import { url } from '@irpclib/r2-image';

const src = url('photos/vacation.jpg', { size: 640, format: 'webp' });
```
- **Frontend Footprint**: Native `<img>` tags with zero client-side JavaScript, zero framework wrappers, and zero hydration cost.
- **Orientation Normalization (`?s=640`)**: Caps the **longest edge** to 640px regardless of whether the photo is portrait (640h × 480w) or landscape (640w × 480h), preventing grid distortion.
- **Portability**: Functions identically across React, Vue, Svelte, Astro, plain HTML, iOS, Android, and Flutter.

#### Vercel

Framework `<Image />` component wrapper:

```tsx [src/Avatar.tsx]
import Image from 'next/image';

export function UserAvatar() {
  return (
    <Image
      src="https://hebbkx1anhila5yf.public.blob.vercel-storage.com/avatar.png"
      alt="User Avatar"
      width={128}
      height={128}
      priority
    />
  );
}
```
- **Frontend Footprint**: Renders through Next.js React component runtime.
- **Orientation**: Requires predefined width and height dimensions.
- **Portability**: Designed for Next.js applications; non-Next.js clients require constructing image proxy URLs.

#### Cloudflare Images

Proprietary vendor URLs:

Predefined named variants must be configured in advance via the dashboard or API, while URL-based flexible transformations (`/w=400,sharpen=3`) require an account-level opt-in and cannot be combined with signed URLs:

```html
<img
  src="https://imagedelivery.net/7901844b20ef/b02d8f99-90bc-43cf-26e7-573516598500/thumbnail"
  alt="User Avatar"
/>
```
- **Frontend Footprint**: Native `<img>` tag tied to Cloudflare's proprietary delivery domain.
- **Portability**: Database stores opaque IDs; switching providers requires bulk migration scripts.

## Key Architectural Takeaways

1. **At-Cost COGS vs. SaaS Markups**: R2 Image executes on Cloudflare Containers (`standard-2`), paying **~$0.0099 per 1,000 transforms** based strictly on actual CPU execution time (~276 ms). Managed SaaS services bill flat transformation fees ($0.50/1k on Cloudflare, $0.08/1k on Vercel) that embed heavy vendor margins.
2. **Zero-Egress Edge Delivery**: In high-traffic image delivery, bandwidth egress is typically the single largest line item. R2 Image delivers cached variants over Cloudflare’s global network with zero egress fees from R2 and Workers (with 1 TB included container egress).
3. **Cost-Effective Persistent Storage**: Storing original assets and cached variants in Cloudflare R2 costs **$0.015 / GB-month**, saving 35% to 65% compared to Vercel Blob ($0.023 to $0.041 / GB-month).
4. **Data Sovereignty**: Assets reside in standard S3-compatible R2 buckets with clean relative paths (`users/avatar.png`), completely free from proprietary vendor database IDs or URL schemas.
