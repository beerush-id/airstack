# Image Delivery

Images stored in R2 are served through standard HTTP GET requests using plain `<img>` tags. When an image is requested with transformation parameters, the Cloudflare Worker checks for an existing variant in R2. On a cache hit, the variant is returned immediately from storage with edge cache headers; on a cache miss, the container resizer generates the variant, persists it back to R2, and serves it.

## Delivery URLs

Constructs a public delivery URL with requested transformations, automatically prepending your configured base URL.

```ts
url(path: string, options?: Resize, base?: string): string
```

### Parameters

- `path` *(string)*: Stored image path in R2 (e.g. `'photos/hero.jpg'`).
- `options` *(Resize, optional)*: Transformation parameters (`size`, `width`, `height`, `format`, `quality`, `fit`, `blur`, `name`).
- `base` *(string, optional)*: Optional base URL override (defaults to the value set via `configure({ baseUrl })`).

### Return Value

Returns a formatted URL string with query parameters (e.g. `'https://cdn.example.com/photos/hero.jpg?s=640&f=webp'`).

### Usage

```tsx
import { url } from '@irpclib/r2-image';

// Standard HTML <img> tag with manually constructed query
<img src="https://cdn.example.com/photos/hero.jpg?s=640&f=webp" alt="Hero" />

// Or constructed with the url() helper
<img src={url('photos/hero.jpg', { size: 640, format: 'webp' })} alt="Hero" />
```

## Longest-Edge Orientation Normalization

If you need to resize images with mixed orientations (such as portrait and landscape photos) without distorting aspect ratios, you can use the `size` (or `s`) parameter. It caps whichever edge is longest and scales the opposing axis proportionally:

- **Landscape images**: caps the width and scales the height proportionally.
- **Portrait images**: caps the height and scales the width proportionally.
- **Square images**: scales both axes equally.

```ts [src/gallery.ts]
import { url } from '@irpclib/r2-image';

// Bounds the longest edge to 640px regardless of whether the photo is landscape or portrait.
const photoUrl = url('gallery/photo.jpg', { size: 640, format: 'webp' });
// Generated URL: /gallery/photo.jpg?s=640&f=webp
```

## Abuse Prevention with Allowed Sizes

If you need to protect your infrastructure from arbitrary resizing queries and uncontrolled compute costs, you can declare an `allowedSizes` whitelist in your worker configuration.

```ts [src/worker.ts]
import { createWorker } from '@irpclib/r2-image/worker';

export default createWorker({
  sizes: [
    { name: 'thumbnail', width: 128, height: 128, format: 'webp' },
  ],
  allowedSizes: [
    128,
    256,
    640,
    1024,
    { name: 'cover', width: 1200, height: 630, format: 'webp' },
  ],
});
```

When an incoming query requests dimensions outside the permitted whitelist, the worker skips container transformation entirely and serves the original image with standard caching headers.

## Delivery Gateway for Existing Buckets

If your application already stores images in an R2 bucket (uploaded via S3 API, Django, Rails, Laravel, Node.js, or external pipelines), you don't need to adopt the upload client or migrate existing files.

R2 Image functions as a drop-in optimization CDN layer on top of any existing bucket:

- **Original Passthrough**: Requesting an existing asset without parameters (e.g. `/photos/avatar.png`) streams the original file directly from R2 with permanent edge cache headers.
- **On-Demand First View**: Requesting with transformation parameters (e.g. `/photos/avatar.png?s=640&f=webp`):
  1. Checks R2 variant storage for an existing copy.
  2. On a cache miss, reads the original file from your bucket, transforms it via the private container resizer, and saves the new variant to R2 in the background.
  3. Serves the optimized WebP to the visitor.
- **Subsequent Views**: All subsequent requests are served straight from Cloudflare Edge Cache or R2 storage with zero container execution.

## Query Parameters Reference

The delivery worker supports these query parameters on image URLs:

| Parameter | Query Key | Description |
| :--- | :--- | :--- |
| Named Preset | `name`, `v` | Resolves a pre-configured variant defined in the worker configuration. |
| Longest Edge | `s`, `size` | Constrains the maximum dimension across width and height while maintaining aspect ratio. |
| Target Width | `w`, `width` | Sets an explicit pixel width. |
| Target Height | `h`, `height` | Sets an explicit pixel height. |
| Image Format | `f`, `format` | Encodes output as WebP, AVIF, PNG, or JPEG. |
| Quality | `q`, `quality` | Sets compression quality from 1 to 100. |
| Fit Strategy | `fit` | Controls content fitting (`cover`, `contain`, `inside`). |
| Blur Radius | `b`, `blur` | Applies Gaussian blur for low-quality image placeholders. |
