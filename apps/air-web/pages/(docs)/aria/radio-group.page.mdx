# AirLib Headless Radio Group

A radio group looks simple until you build a custom one: native `<input type="radio">` tags enforce mutual exclusivity but resist custom layout, while rich card containers need hand-rolled `role="radiogroup"`, circular arrow roving focus, fallback tab stops when unselected, `aria-required`, and form isolation. **AirLib Headless Radio Group** (`aria('radio-group')`) coordinates single-selection across native inputs or custom cards — circular roving focus, instant selection, and validation projection included, without dictating markup or styles.

```tsx
const group = aria('radio-group', props);

<div ref={group.ref} {...group.props} />
```

```tsx
import { aria } from '@airlib/aria';
import { setup } from '@airlib/react';
import type { ComponentProps } from 'react';

type DemoRadioGroupProps = ComponentProps<'div'> & {
  value?: string;
  name?: string;
  orientation?: 'horizontal' | 'vertical';
  required?: boolean;
  disabled?: boolean;
};

const DemoRadioGroup = setup<DemoRadioGroupProps>((props) => {
  const group = aria('radio-group', props);

  return () => (
    <div ref={group.ref} {...group.props} className="demo-radio-group">
      {props.children}
    </div>
  );
}, 'DemoRadioGroup');

type DemoRadioCardProps = ComponentProps<'div'> & {
  value: string;
  title: string;
  price: string;
  disabled?: boolean;
};

const DemoRadioCard = setup<DemoRadioCardProps>((props) => {
  const radio = aria('radio', props, { native: false });

  return () => (
    <div ref={radio.ref} {...radio.restProps(['title', 'price', 'children'])} className="demo-radio-card">
      <strong>{props.title}</strong>
      <span>{props.price}</span>
    </div>
  );
}, 'DemoRadioCard');
```

## Radio Group

Single-selection group controller that compiles `role="radiogroup"` and coordinates mutual exclusivity.

```ts
aria<E extends BaseElement = HTMLElement, T extends Primitive = Primitive>(
  role: 'radio-group',
  props?: RadioGroupProps<T>
): RadioGroupAria<E, RadioGroupProps<T>>
```

### Usage

### Parameters

- `props.value` *(Primitive, optional)*: Active radio value token. Once selected, cannot be deselected through itself.
- `props.name` *(string, optional)*: HTML form field name forwarded to native radio inputs.
- `props.orientation` *('vertical' | 'horizontal', optional, default `'vertical'`)*: Keyboard navigation axis and compiled `aria-orientation`.
- `props.required` *(boolean, optional, default `false`)*: Compiles `aria-required="true"` when true.
- `props.invalid` *(boolean | 'grammar' | 'spelling', optional)*: Validation state compiled to `aria-invalid`.
- `props.id` *(string, optional)*: DOM element identifier.
- `props.disabled` *(boolean, optional)*: Disables the entire radio group and suppresses arrow navigation.

### How it behaves

- Compiles `role="radiogroup"`, `aria-orientation`, and `aria-required="true"` when required.
- Manages roving focus across child radios along the configured axis. Arrow navigation wraps circularly at boundaries and automatically selects the newly focused candidate in one transition.
- When `value` is `null` or unselected, the roving tab stop falls back to the first enabled radio so the group remains reachable via `Tab`.
- Re-activating an already checked radio is idempotent. `Enter` commits nothing.
- The compiled attributes carry only accessibility metadata; `name` and `value` are preserved for native form submission.

## Radio Items

Individual choices within a radio group are managed using the `radio` role controller (`aria('radio')`). See the [Radio](/docs/aria/radio) documentation for complete parameter reference, native input binding, and custom host configurations.

## Keyboard Navigation

- **ArrowDown / ArrowRight**: Moves roving focus to the next enabled radio and selects it immediately.
- **ArrowUp / ArrowLeft**: Moves roving focus to the previous enabled radio and selects it immediately.
- **Home / End**: Moves focus directly to the first or last enabled radio in the group and selects it immediately.
- **Space**: Selects an unchecked focused radio; idempotent on an already selected radio.
- **Enter**: Inert (commits nothing).

## What you get

- **One Tab stop.** Tabbing into the group lands on the selected radio (or first enabled radio when none is selected); tabbing again exits the group completely.
- **Mutual exclusivity.** Selecting an option sets it as the active choice and deselects all siblings automatically.
- **Arrow navigation with instant selection.** Arrow keys navigate across options and select immediately in one transition.
- **Idempotent selection.** Once selected, activating a radio button again remains selected.
- **Support for rich cards.** Build custom card elements using `native: false` while retaining full roving focus and arrow navigation.
