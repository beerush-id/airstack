# Headless Toggle

A two-state button has to hold its state, show it, and invert on command — and inside a group of them, every member has to agree on one shared value. Hand-rolled, that means wiring `aria-pressed`, the tab stop, the keys, and the group sync yourself.

**Headless Toggle** gives you a toggle that behaves on any element: pressed inversion with a change event on its own, and one shared value when several of them form a group.

```tsx
const toggle = aria('toggle', props, { native: false });

<div ref={toggle.ref} {...toggle.restProps(['children'])} />
```

:::interactive[Toggles]
```tsx
import { aria } from '@airlib/aria';
import { setup } from '@airlib/react';
import type { ComponentProps } from 'react';

type DemoToggleProps = ComponentProps<'div'> & {
  pressed?: boolean;
  disabled?: boolean;
};

const DemoToggle = setup<DemoToggleProps>((props) => {
  const toggle = aria('toggle', props, { native: false });

  return () => (
    <div ref={toggle.ref} {...toggle.restProps(['children'])} className="demo-toggle">
      {props.children}
    </div>
  );
}, 'DemoToggle');
```
```html
<div className="demo-toggle-stack">
  <DemoToggle>Bold</DemoToggle>
  <DemoToggle pressed>Italic</DemoToggle>
  <DemoToggle disabled>Underline</DemoToggle>
</div>
```

:::tip
Inside a group, give each member a `value` and let the group hold the state. Members derive their pressed state from the shared value — setting `pressed` on a grouped member yourself fights the group.
:::

## Toggle

**One two-state trigger.** Pressed or not, on its own or as a group member.

### Usage

```ts
aria<E extends BaseElement = HTMLButtonElement>(
  role: 'toggle',
  props?: ToggleProps,
  options?: ToggleOptions
): ToggleAria<E>
```

:::code-group

```tsx [React]
import { aria } from '@airlib/aria';
import { setup } from '@airlib/react';
import type { ComponentProps } from 'react';

type ToggleButtonProps = ComponentProps<'button'> & {
  pressed?: boolean;
  disabled?: boolean;
};

const ToggleButton = setup<ToggleButtonProps>((props) => {

  return () => (
    <button ref={toggle.ref} {...toggle.restProps(['children'])}>

```

### Parameters

_What you pass in. The props object stays live — change a value on it and the part follows._

- **value** _string | number | boolean, optional_: This member's token inside a [toggle group](/docs/aria/toggle-group). Standalone toggles don't need one.
- **pressed** _boolean, optional_: The state when standalone. Inside a group the shared value decides instead.
- **disabled** _boolean, optional_: Blocks inversion and state changes.
- **onchange** _(event: CustomEvent&lt;boolean&gt;) =&gt; void, optional_: Called after each commit, with the new pressed state in `detail`.

### Options

_What you fix when you create it. Read once, never reactive._

- **native** _boolean, optional, default `true`_: Pass `false` when the host isn't a `<button>`, and the role, the tab stop, and the keys come with it.

### Properties

_What you read or write on the instance afterwards._

- **pressed** _boolean_: Whether it is pressed. **Read and write** — assigning it inverts the state without a user interaction.
- **value** _string | number | boolean_: This member's token.
- **disabled** _boolean_: Whether it is locked, **including by the group**.
- **id** _string_: This toggle's identifier in the DOM.

### Methods

_What you call on the instance._

- **`select()`**: Presses it. _Does nothing while disabled._
- **`deselect()`**: Releases it. _Does nothing while disabled._
- **`toggle()`**: Inverts it.

### How it behaves

- **Inversion is the whole interaction.** A click, `Enter`, or `Space` flips the state; a cancelled flip commits nothing.
- **Every commit is observable.** One bubbling `change` per inversion, carrying the new state.
- **Custom hosts become toggles.** With `native: false`, a `<div>` or `<span>` gets the button role, the pressed state, a tab stop, and the keys.
- **Grouped members share one value.** Single-select sets or clears it; multi-select toggles membership — the member's pressed state follows.
- **Safe in forms.** A native host carries `type="button"`, so a toggle never submits.

### Events

_What it tells you._

- **`change`** — fires after each commit, with the new pressed state in `detail`.

### Navigation

_What the keys do._

- **`Tab`** — focuses the toggle. A disabled one leaves the tab order.
- **`Space`** — stops the page scrolling on keydown and inverts on keyup; a cancelled keydown disarms the keyup.
- **`Enter`** — inverts on keydown.

## API Reference

What you can actually use, with every alias and every base resolved to what it really is. Each attribute dictionary also takes the standard HTML attributes and event handlers for its host, and each props dictionary takes any extra keys you want forwarded.

### Toggle

```ts
interface ToggleProps {
  value?: string | number | boolean;
  pressed?: boolean;
  disabled?: boolean;
  onchange?: (event: CustomEvent<boolean>) => void;
}

interface ToggleOptions {
  native?: boolean;
}

interface ToggleAttributes {
  role?: 'button';
  type?: 'button';
  'aria-pressed': 'true' | 'false';
  disabled?: boolean;
  tabindex?: number;
}

declare class ToggleAria {
  id: string;

  get pressed(): boolean;
  set pressed(value: boolean);
  get value(): string | number | boolean;
  get disabled(): boolean;

  select(): void;
  deselect(): void;
  toggle(): void;
}
```

### On every one of them

```ts
ref: (element: E | null) => (() => void) | undefined;

get props(): T;
get attributes(): Record<string, unknown>;
get ownKeys(): string[];
get isNative(): boolean;
get current(): E | null;
set current(element: E | null);

assign(props: Partial<T>): void;
refine(refiner: (props: T, attrs: A) => Partial<A> | void): (destroyed?: boolean) => void;
on<K extends keyof HTMLElementEventMap>(type: K, handler: (event: HTMLElementEventMap[K]) => void): () => void;
on(type: string, handler: (event: Event) => void): () => void;
restProps(omit?: (keyof T)[]): T;
destroy(): void;
```

- **`attributes`** is the dictionary you spread; **`ref`** is what you bind the element with; **`props`** is the full props dictionary for spreading onto the host; **`restProps(omit)`** hands back your props with the keys you name left out.
- **`assign()`** changes several parameters at once, **`refine()`** adds attributes of your own, **`on()`** listens for anything the part fires, **`destroy()`** tears it down.
