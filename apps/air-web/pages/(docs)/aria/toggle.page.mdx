# Headless Toggle

A toggle is a button that keeps its state: pressed or not, announced as such, and inverted by activation.

Getting it right means **inverting exactly once per activation**, **announcing the pressed state on a host that has no native equivalent**, **staying inert while locked**, and **sharing one value when several toggles form a group**.

**Headless Toggle** does all of that for you, and leaves the markup and the styling entirely yours.

```tsx
const toggle = aria('toggle', props);

<button ref={toggle.ref} {...toggle.restProps(['children'])} />
```

:::interactive[Formatting Bar]

import { aria } from '@airlib/aria';
import { setup } from '@airlib/react';
import type { ComponentProps } from 'react';

type DemoToggleProps = ComponentProps<'button'> & {
  pressed?: boolean;
  disabled?: boolean;
};

const DemoToggle = setup<DemoToggleProps>((props) => {
  const toggle = aria('toggle', props);

  return () => (
    <button ref={toggle.ref} {...toggle.restProps(['children'])} className="demo-toggle">
      {props.children}
    </button>
  );
}, 'DemoToggle');

:::tip
**Inside a group, the group owns the state.** Give each member a `value` and read the shared value instead of setting `pressed`: a member with a token derives its pressed state from the group, while a member without one stays on its own.
:::

## Toggle

**One two-state trigger.** Pressed or not, on its own or as a group member.

### Usage

```ts
aria<E extends BaseElement = HTMLButtonElement>(
  role: 'toggle',
  props?: ToggleProps,
  options?: ToggleOptions
): ToggleAria<E>
```

:::code-group

```tsx [React]
import { aria } from '@airlib/aria';
import { setup } from '@airlib/react';
import type { ComponentProps, ReactNode } from 'react';

type ToggleButtonProps = ComponentProps<'button'> & {
  pressed?: boolean;
  disabled?: boolean;
  children: ReactNode;

  return () => (

    </button>
  );
}, 'ToggleButton');
```

### Parameters

_What you pass in. The props object stays live — change a value on it and the part follows._

- **pressed** _boolean, optional, default `false`_: The state when standalone. A grouped member reads the shared value instead.
- **value** _Primitive, optional_: The token this toggle contributes to a group. Give one and the toggle is a member; leave it out and it keeps its own state.
- **disabled** _boolean, optional_: Locks the toggle. A group's own `disabled` reaches it the same way.
- **onchange** _(event: CustomEvent&lt;boolean | Primitive | Primitive[]&gt;) =&gt; void, optional_: Called after each commit. Standalone `detail` is the new pressed boolean; a grouped member carries the group's value instead.

### Options

_What you fix when you create it. Read once, never reactive._

- **native** _boolean, optional, default `true`_: Set `false` when the host is not a real `<button>`, and the role, the tab stop, the keys, and the `<label>` click polyfill come with it.

### Properties

_What you read or write on the instance afterwards._

- **pressed** _boolean_: Whether it is pressed. **Writing it presses or releases the toggle** through the same commit path as a click, and a write is refused while disabled.
- **value** _Primitive_: The token this toggle contributes to a group.
- **disabled** _boolean_: Whether it is locked, **including by the group**.
- **id** _string_: The toggle's own identifier — `button-<n>` standalone, and `<group-id>-button-<value>` when the group carries an `id` and the toggle a `value`.

### Methods

_What you call on the instance._

- **`select()`**: Presses it. _Does nothing while disabled._
- **`deselect()`**: Releases it. _Does nothing while disabled._
- **`toggle()`**: Inverts it. _This is the path every activation arrives on._

### How it behaves

- **Inversion is the whole interaction.** One commit per activation: a click, a `Space` that lands on keyup, or an `Enter` on keydown. A canceled trigger commits nothing.
- **Every commit is observable.** One bubbling `change` carrying the new state, and a commit that lands on the state it started from stays silent.
- **Both hosts announce.** `aria-pressed` is compiled either way, because HTML has no pressed state. A real `<button>` also gets `type="button"` and `disabled`; a custom host gets `role="button"`, a tab stop, and the `aria-disabled` mirror.
- **A `<button>` host is left to the browser.** With `native: true` no key handling is added and nothing is canceled — activation arrives as the click the browser generates.
- **Locked means refused.** Click, keys, and writes are refused while disabled. A disabled `<button>` fires no click at all; a custom host refuses it without stopping it, so a listener above the toggle still sees the activation.
- **Grouped members share one value.** A single-select member sets the shared value when pressed and clears it when released; a multi-select member adds and removes its token. The group's `disabled` locks every member.
- **Group membership changes the tab stop.** A member with a `value` compiles `0` only while it is the pressed one and `-1` otherwise, so a single-select group holds one stop — a multi-select group holds one per pressed member.
- **Safe in forms.** A native host carries `type="button"`, and the selection token is consumed by the controller rather than written to the field.

### Events

_What it tells you._

- **`change`** — fires when the state really flips, with the new state in `detail`. A grouped member carries the group's shared value there instead: a token in a single-select group, the current array in a multi-select one. Canceled triggers, disabled toggles, and writes that change nothing stay silent.

```tsx
const bold = aria('toggle', {
  pressed: false,
  onchange: (event) => setBold(event.detail === true),
});
```

### Navigation

_What the keys do._

- **`Space`** — on a custom host, suppresses the page scroll on keydown and commits on keyup; a canceled keydown never commits, and a held key commits once. On a `<button>` host the browser owns the key and the click it produces.
- **`Enter`** — on a custom host, commits on keydown, once for each press. On a `<button>` host the browser owns it.
- **`Tab`** — reaches a custom host. A disabled toggle leaves the tab order, and a grouped member is only a stop while it is pressed.

## API Reference

What you can actually use, with every alias and every base resolved to what it really is. Each attribute dictionary also takes the standard HTML attributes and event handlers for its host, and each props dictionary takes any extra keys you want forwarded.

### Toggle

```ts
interface ToggleProps {
  pressed?: boolean;
  value?: Primitive;
  disabled?: boolean;
  onchange?: (event: CustomEvent<boolean | Primitive | Primitive[]>) => void;
}

interface ToggleOptions {
  native?: boolean;
}

interface ToggleAttributes {
  id?: string;
  role?: 'button';
  type?: 'button';
  disabled?: boolean;
  tabindex?: number;
  'aria-pressed'?: 'true' | 'false';
  'aria-disabled'?: 'true' | 'false';
}

declare class ToggleAria {
  id: string;
  get pressed(): boolean;
  set pressed(value: boolean);
  get value(): Primitive;
  get disabled(): boolean;

  select(): void;
  deselect(): void;
  toggle(): void;
}
```

### On every one of them

```ts
ref: (element: E | null) => (() => void) | undefined;

get props(): T;
get attributes(): Record<string, unknown>;
get ownKeys(): string[];
get isNative(): boolean;
get current(): E | null;
set current(element: E | null);

assign(props: Partial<T>): void;
refine(refiner: (props: T, attrs: A) => Partial<A> | void): (destroyed?: boolean) => void;
on<K extends keyof HTMLElementEventMap>(type: K, handler: (event: HTMLElementEventMap[K]) => void): () => void;
on(type: string, handler: (event: Event) => void): () => void;
restProps(omit?: (keyof T)[]): T;
destroy(): void;
```

- **`attributes`** is the dictionary you spread; **`ref`** is what you bind the element with; **`props`** is the full props dictionary for spreading onto the host; **`restProps(omit)`** hands back your props with the keys you name left out.
- **`assign()`** changes several parameters at once, **`refine()`** adds attributes of your own, **`on()`** listens for anything the part fires, **`destroy()`** tears it down.
