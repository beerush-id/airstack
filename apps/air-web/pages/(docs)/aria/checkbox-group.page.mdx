# AirLib Headless Checkbox Group

A checkbox group looks simple until you coordinate state across custom cards: native checkboxes in a `<fieldset>` manage independent tab stops but resist layout, while rich multi-select containers require `role="group"`, `aria-label`, ambient set membership, and cascaded group disablement without roving focus. **AirLib Headless Checkbox Group** (`aria('checkbox-group')`) coordinates multi-selection across native inputs or custom cards — ambient array membership, independent tab navigation, and form boundary support included, without dictating markup or styles.

```tsx
const group = aria('checkbox-group', props);

<div ref={group.ref} {...group.props} />
```

import { aria } from '@airlib/aria';
import { setup } from '@airlib/react';
import type { ComponentProps } from 'react';

type DemoCheckboxGroupProps = ComponentProps<'div'> & {

  label?: string;
  disabled?: boolean;

    </div>

## Checkbox Group

Multi-selection container coordinator that compiles `role="group"` and ambiently manages the checked array.

```ts
aria<E extends BaseElement = HTMLElement>(
  role: 'checkbox-group',
  props?: CheckboxGroupProps
): CheckboxGroupAria<E>
```

### Usage

:::code-group

```tsx [React]
import { aria } from '@airlib/aria';
import { setup } from '@airlib/react';
import type { ComponentProps } from 'react';

type CheckboxGroupProps = ComponentProps<'div'> & {
  id?: string;
  value?: string[];
  disabled?: boolean;
  label?: string;
};

const CheckboxGroup = setup<CheckboxGroupProps>((props) => {
  const group = aria('checkbox-group', props);

  return () => (
    <div ref={group.ref} {...group.props}>
      {props.children}
    </div>
  );
});
```

```tsx [SolidJS]
import { aria } from '@airlib/aria';
import { setup } from '@airlib/solid';
import type { ComponentProps } from 'solid-js';

type CheckboxGroupProps = ComponentProps<'div'> & {
  id?: string;
  value?: string[];
  disabled?: boolean;
  label?: string;

const CheckboxGroup = setup<CheckboxGroupProps>((props) => {
  const group = aria('checkbox-group', props);

  return (
    <div ref={group.ref} {...group.props}>
      {props.children}
    </div>
  );
});
```

:::

### Parameters

- `props.value` *(string[], optional, default `[]`)*: Array of currently checked member values.
- `props.disabled` *(boolean, optional)*: Disables the entire group and cascades disablement to all members.
- `props.label` *(string, optional)*: Accessible text label applied via `aria-label`.
- `props.id` *(string, optional)*: Explicit DOM identifier and group namespace.

### How it behaves

- Compiles `role="group"` on non-`<fieldset>` elements, and omits `role` when attached to a native `<fieldset>`.
- Ambiently provides the selection context with `multiple: true` so member checkboxes automatically sync membership without direct prop drilling.
- Activating a member checkbox toggles its presence in `group.value` without clearing sibling items.
- Preserves independent tab stops per WAI-ARIA APG specifications — does not introduce roving focus or swallow arrow keys.

## Checkbox Items

Individual choice units within a checkbox group are managed using the standard `checkbox` role controller (`aria('checkbox')`). See the [Checkbox](/docs/aria/checkbox) documentation for complete parameter reference, native input binding, and tri-state indeterminate configurations.

## Keyboard Navigation

- **Tab**: Moves focus to each individual enabled checkbox in the group sequentially.
- **Shift + Tab**: Moves focus to the previous checkbox in reverse tab order.
- **Space**: Toggles the focused checkbox on and off.
- **Arrow Keys**: Ignored by the group container; native page scrolling or custom composite behaviors remain unaffected.

## What you get

- **APG Compliance.** Respects standard checkbox group design patterns where each member is an independent tab stop without roving focus.
- **Native fieldset awareness.** Automatically omits redundant `role="group"` when bound to a native `<fieldset>`.
- **Ambient set coordination.** Synchronizes checked array state with child `aria('checkbox')` items seamlessly.
- **Disabled cascade.** Disabling the group automatically locks out all member checkboxes.
- **Zero markup lock-in.** Render native `<input type="checkbox">` elements or rich custom interactive cards.
