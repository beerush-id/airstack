# AirLib Headless Popover

The **Popover** widget coordinates non-modal floating overlays anchored to an interactive trigger element. Unlike modal dialogs, popovers are non-modal: they support light dismissal (dismissed on outside clicks or the `Escape` key), preserve access to background content without focus trapping, and restore focus to the trigger upon dismissal.

**AirLib Headless Popover** (`aria('popover')`) is a single-unit self-discovering overlay widget. It automatically links to the host trigger candidate registered in its ambient execution scope (`scope.actionable`, such as a button) or falls back directly to its DOM `parentElement`.

```tsx
const host = aria('button');
const pop = aria('popover');

<button ref={host.ref} {...host.props}>
  Open Settings
  <div ref={pop.ref} {...pop.props}>
    <h4>Quick Settings</h4>
    <p>This floating overlay dismisses on outside clicks or Escape.</p>
  </div>
</button>
```

:::interactive[Self-Discovering Popover]
```tsx
import { aria, type PopoverProps } from '@airlib/aria';
import { setup, teleport } from '@airlib/react';
import type { ComponentProps } from 'react';

const Button = setup<ComponentProps<'button'>>((props) => {
  const btn = aria('button', props);
  return () => (
    <button ref={btn.ref} {...btn.props}>
      {props.children}
    </button>
  );
});

const Popover = setup<PopoverProps>((props) => {
  const pop = aria('popover', props);

  return () => {
    if (!pop.open) return null;

    return teleport(
      <div ref={pop.ref} {...pop.props}>
        {props.children}
      </div>
    );
  };
});

const PopoverDemo = (props: PopoverProps) => (
  <div className="popover-container">
    <Button className="popover-trigger">
      <span>Settings Menu</span>
      <span aria-hidden="true">▾</span>
      <Popover className="popover-panel" xDir={props.xDir} yDir={props.yDir}>
        <h4 className="popover-title">Quick Settings</h4>
        <p className="popover-text">Adjust project preferences without leaving this screen.</p>
      </Popover>
    </Button>
  </div>
);
```

## Anatomy & Scope Discovery

The popover widget is applied directly to the floating overlay element:

```ts
const pop = aria('popover', props?: PopoverProps, options?: PopoverOptions);
```

### Automatic Candidate Discovery

When initialized, `PopoverAria` resolves its trigger anchor in two tiers:

1. **Ambient Scope (`this.scope?.actionable`)**: If nested inside an interactive component that marks itself actionable (such as `ButtonAria`, `LinkAria`, or `ToggleAria`), the popover automatically registers an attribute refiner on that controller to inject `aria-haspopup="dialog"`, `aria-expanded`, and `aria-controls`.
2. **DOM Fallback (`this.element.parentElement`)**: When mounted directly inside a plain HTML host without an enclosing controller, `attach()` configures the parent element with the required ARIA linkage attributes and click listeners, cleaning them up upon detachment.

### Usage

:::code-group

```tsx [React]
import { aria, type PopoverProps } from '@airlib/aria';
import { setup, teleport } from '@airlib/react';

export const Popover = setup<PopoverProps>((props) => {
  const pop = aria('popover', props);

  return () => {
    if (!pop.open) return null;

    return teleport(
      <div ref={pop.ref} {...pop.props}>
        {props.children}
      </div>
    );
  };
});
```

```tsx [SolidJS]
import { aria, type PopoverProps } from '@airlib/aria';
import { setup } from '@airlib/solid';
import { Show } from 'solid-js';

export const Popover = setup<PopoverProps>((props) => {
  const pop = aria('popover', props);

  return (
    <Show when={pop.open}>
      <div ref={pop.ref} {...pop.props}>
        {props.children}
      </div>
    </Show>
  );
});
```

## Architectural & Accessibility Contracts

### Events

- `onopen` is called when the popover opens
- `onclose` is called when the popover closes
- `ontoggle` is called with the open state after the popover toggles, and the same `toggle` `CustomEvent<boolean>` (`bubbles: false`) dispatches on the panel:

```ts
const popover = aria('popover', {
  open: false,
  ontoggle: (event) => {
    const isOpen = event.detail;
  },
});
```

### Semantic Layering

| Host Element | Attributes Emitted | Semantics & Behavior |
| :--- | :--- | :--- |
| **Trigger (`<button>`)** | `aria-haspopup="dialog"`, `aria-expanded`, `aria-controls` | Native button activation; reflects open/closed state to assistive technology. |
| **Panel (Custom)** | `id`, `role="dialog"`, `hidden` | Hidden when closed; light dismissal via outside pointerdown and Escape key. Non-trapping focus. |
| **Native Popover Panel** | `popover="auto"` or `"manual"` | Integrates with browser native popover top-layer elevation and light dismissal when `options.native = true`. |

## Entity Specifications

### `PopoverAria`

- **Role / Type**: Overlay Widget (`aria('popover')`)
- **Parameters (`PopoverProps`)**:
  - `open` *(boolean, optional, default `false`)*: Controls visibility of the popover overlay.
  - `dismissable` *(boolean, optional, default `true`)*: Enables Escape key dismiss and outside click light dismissal.
  - `lightDismiss` *(boolean, optional, default `true`)*: Alias for `dismissable`.
  - `id` *(string, optional)*: Explicit base identifier used to coordinate `aria-controls`. Auto-generated by default.
  - `xDir` *('before' | 'after' | 'left' | 'between' | 'right', optional)*: Horizontal placement token.
  - `yDir` *('top' | 'bottom' | 'above' | 'below' | 'between', optional)*: Vertical placement token.
- **Options (`PopoverOptions`)**:
  - `popupRole` *('dialog' | 'menu', optional, default `'dialog'`)*: Semantic role emitted on panel.
  - `native` *(boolean, optional)*: Emits native HTML `popover` attribute when true.
- **Controller Properties & Methods**:
  - `open` *(boolean)*: Reactive open state.
  - `dismissable` *(boolean)*: Resolved light dismissal flag.
  - `popupRole` *('dialog' | 'menu')*: Resolved popup role.
  - `show()`: Opens the popover.
  - `close()`: Closes the popover.
  - `toggle()`: Toggles the open state.

## Keyboard Navigation

- **Escape**: Light-dismisses the open popover if `dismissable: true`, restoring focus to the opening trigger button.
- **Space / Enter**: Activates the trigger button to toggle the popover open and closed.
- **Tab**: Traverses focus into interactive controls inside the popover and smoothly out into the surrounding document without trapping.

## What you get

- **Self-discovering linkage.** Overlays discover their actionable host automatically from ambient scope or parent DOM hierarchy without manual ID wiring.
- **Non-modal lightness.** Overlay stays non-modal, allowing keyboard and pointer users to interact with background content freely.
- **Automatic focus restoration.** Focus lands cleanly back on the opening trigger when dismissed by keyboard or pointer.
- **Light dismiss lifecycle.** Automatically closes when clicking outside or pressing Escape, preventing toggle race conditions with trigger exclusion.
- **Native Popover API sync.** Seamlessly binds to HTML `popover="auto"` or `popover="manual"` attributes when native support is detected.
