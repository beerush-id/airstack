# Headless Link

A link has to announce itself, expose its destination, and step aside cleanly when that destination is unavailable. A real `<a>` does the first two and has no disabled state at all — an unavailable link either still navigates, or loses its `href` and vanishes from assistive technology. A `<span>` standing in for a link has to be given its role, its tab stop, and its `Enter` key by hand.

**Headless Link** makes any element a navigation trigger: the destination on any host, a real disabled state that blocks navigation while keeping the destination discoverable, the current-page mark, and the keyboard on custom hosts.

```tsx
const link = aria('link', props);

<a ref={link.ref} {...link.restProps(['children'])} />
```

:::interactive[Links]
```tsx
import { aria } from '@airlib/aria';
import { setup } from '@airlib/react';
import type { ComponentProps } from 'react';

type DemoLinkProps = ComponentProps<'a'> & {
  disabled?: boolean;
  current?: boolean;
};

const DemoLink = setup<DemoLinkProps>((props) => {
  const link = aria('link', props);

  return () => (
    <a ref={link.ref} {...link.restProps(['children'])} className="demo-link">
      {props.children}
    </a>
  );
}, 'DemoLink');

type DemoSpanLinkProps = ComponentProps<'span'> & {
  disabled?: boolean;
};

const DemoSpanLink = setup<DemoSpanLinkProps>((props) => {
  const link = aria('link', props, { native: false });

  return () => (
    <span ref={link.ref} {...link.restProps(['children'])} className="demo-link">
      {props.children}
    </span>
  );
}, 'DemoSpanLink');
```

## Link

**One navigation trigger.** It behaves like an anchor whether the host is one or not.

### Usage

```ts
aria<E extends BaseElement = HTMLAnchorElement>(
  role: 'link',
  props?: LinkProps,
  options?: LinkOptions
): LinkAria<E>
```

:::code-group

```tsx [React]
import { aria } from '@airlib/aria';
import { setup } from '@airlib/react';
import type { ComponentProps } from 'react';

type LinkProps = ComponentProps<'a'> & {
  href?: string;
  target?: string;
  disabled?: boolean;
  current?: boolean;
  page?: number;
};

const Link = setup<LinkProps>((props) => {
  const link = aria('link', props);

  return () => (
    <a ref={link.ref} {...link.restProps(['children'])}>
      {props.children}
    </a>
  );
}, 'Link');
```

```tsx [SolidJS]
  );

```

### Parameters

_What you pass in. The props object stays live — change a value on it and the part follows._

- **href** _string, optional_: The destination. **Kept while disabled**, so the link stays discoverable.
- **target** _string, optional_: The browsing context, such as `_blank`.
- **disabled** _boolean, optional_: Blocks navigation, announces the link as unavailable, and parks it outside the tab order.
- **current** _boolean, optional_: Forces the current-page mark. Left unset, the destination is matched against the page you are on.
- **page** _number, optional_: The position this link commits into an enclosing [pagination](/docs/aria/pagination) when it activates.

### Options

_What you fix when you create it. Read once, never reactive._

- **native** _boolean, optional, default `true`_: Pass `false` for a `<span>` or `<div>` host and the role, the tab stop, and `Enter` come with it.

### Properties

_What you read or write on the instance afterwards._

- **href** _string_: The destination in force, kept while disabled.
- **isCurrent** _boolean_: Whether this is the page you are on, by override or by match.
- **disabled** _boolean_: Whether navigation is blocked.

### How it behaves

- **Native first.** On a real `<a>` nothing redundant is added and the browser keeps handling activation.
- **A disabled state HTML doesn't have.** The destination stays on the element, the click is cancelled instead, and the link is announced as unavailable rather than gone.
- **Custom hosts become links.** With `native: false`, a `<span>` or `<div>` gets the link role, a tab stop, and `Enter` activation. `Space` stays out of it — that is a button's key.
- **New-tab gestures behave like the browser's.** `Ctrl` / `Cmd` / `Shift`-click and middle-click open the destination in a new tab unless `target` says otherwise.
- **The current page says so.** Matching the page you are on — or `current: true` — marks the link as it.
- **It can drive a pagination.** A link carrying `page` writes that position into the enclosing pagination when it activates; new-tab gestures open a tab and commit nothing, because you never left the page.
- **Inside a pagination or a breadcrumb, one tab stop.** Only the current link takes it; the rest are reached with the arrow keys.

### Navigation

_What the keys do._

- **`Tab`** — focuses the link. A disabled link is parked outside the tab order on either host; inside a pagination or a breadcrumb only the current link takes the stop.
- **`Enter`** — activates the link. A native anchor does this in the browser; a custom host gets it from the link.
- **`Space`** — does nothing on purpose. `Space` activates buttons, not links, and the page keeps scrolling.

## API Reference

What you can actually use, with every alias and every base resolved to what it really is. Each attribute dictionary also takes the standard HTML attributes and event handlers for its host, and each props dictionary takes any extra keys you want forwarded.

### Link

```ts
interface LinkProps {
  href?: string;
  target?: string;
  disabled?: boolean;
  current?: boolean;
  page?: number;
}

interface LinkOptions {
  native?: boolean;
}

interface LinkAttributes {
  role?: 'link';
  href?: string;
  target?: string;
  tabindex?: number;
  'aria-disabled'?: 'true' | 'false';
  'aria-current'?: 'page';
}

declare class LinkAria {
  get href(): string | undefined;
  get isCurrent(): boolean;
  get disabled(): boolean;
}
```

### On every one of them

```ts
ref: (element: E | null) => (() => void) | undefined;

get props(): T;
get attributes(): Record<string, unknown>;
get ownKeys(): string[];
get isNative(): boolean;
get current(): E | null;
set current(element: E | null);

assign(props: Partial<T>): void;
refine(refiner: (props: T, attrs: A) => Partial<A> | void): (destroyed?: boolean) => void;
on<K extends keyof HTMLElementEventMap>(type: K, handler: (event: HTMLElementEventMap[K]) => void): () => void;
on(type: string, handler: (event: Event) => void): () => void;
restProps(omit?: (keyof T)[]): T;
destroy(): void;
```

- **`attributes`** is the dictionary you spread; **`ref`** is what you bind the element with; **`props`** is the full props dictionary for spreading onto the host; **`restProps(omit)`** hands back your props with the keys you name left out.
- **`assign()`** changes several parameters at once, **`refine()`** adds attributes of your own, **`on()`** listens for anything the part fires, **`destroy()`** tears it down.
