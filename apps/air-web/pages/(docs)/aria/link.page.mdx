# AirLib Headless Link

Navigation triggers must announce themselves as links, expose their destination, and deactivate cleanly when that destination is unavailable. HTML `<a>` covers most of this natively, but it has no disabled state: an unavailable link either stays navigable or gets its `href` ripped out, which silently drops it from assistive technology. Custom link elements built from `<span>` or `<div>` must add `role="link"`, a tab stop, and `Enter` activation by hand. **AirLib Headless Link** (`aria('link')`) turns any element into a navigation trigger — `href` and `target` projection on any host, a real disabled state that keeps the destination discoverable while blocking navigation, current-page announcement, and `Enter` polyfills for custom hosts.

```tsx
const link = aria('link', props);

<span ref={link.ref} {...link.props}>Documentation</a>
```

## Link

Navigation trigger with destination projection, real disabled lockout, and current-page announcement.

```ts
aria<E extends BaseElement = HTMLAnchorElement>(
  role: 'link',
  props?: LinkProps,
  options?: LinkOptions
): LinkAria<E>
```

### Usage

:::code-group

```tsx [React] executable
import { aria } from '@airlib/aria';
import { setup } from '@airlib/react';
import type { ComponentProps } from 'react';

type LinkProps = ComponentProps<'a'> & {
  disabled?: boolean;
  current?: boolean;
};

const Link = setup<LinkProps>((props) => {
  const link = aria('link', props);

  return () => (
    <a ref={link.ref} {...link.restProps(['children'])}>
      {props.children}
    </a>
  );
}, 'Link');
```

```tsx [SolidJS]
import { aria } from '@airlib/aria';
import { setup } from '@airlib/solid';
import type { ComponentProps } from 'solid-js';

type LinkProps = ComponentProps<'a'> & {
  disabled?: boolean;
  current?: boolean;
};

const Link = setup<LinkProps>((props) => {
  const link = aria('link', props);

  return (
    <a ref={link.ref} {...link.restProps(['children'])}>
      {props.children}
    </a>
  );
});
```

:::

`disabled` is omitted explicitly: it is a controller input, not an anchor attribute, so forwarding it would leak an invalid `disabled` attribute onto the DOM.

### Parameters

- `props.href` *(string, optional)*: Target resource URL. Kept while disabled so the link stays discoverable.
- `props.target` *(string, optional)*: Target browsing context, such as `_blank`.
- `props.disabled` *(boolean, optional)*: Blocks navigation via `preventDefault`, announces `aria-disabled`, and parks `tabindex` at `-1`.
- `props.current` *(boolean, optional)*: Current-page override. When unset, `href` is matched against the ambient `linkCtx` URL. Inside an `aria('pagination')`, the current link is the run's only tab stop (`tabindex="0"`); the other page links park at `-1`.
- `props.page` *(number, optional)*: Page position this link commits into an enclosing `aria('pagination')` when it activates. Owned by the controller, so it never reaches the DOM as an attribute.
- `options.native` *(boolean, optional, default `true`)*: Pass `false` when binding to a custom `<span>` or `<div>` host.

### How it behaves

On a native `<a>`, no `role` is emitted. Disabling keeps `href` on the element and cancels the click instead, so the destination stays discoverable while nothing navigates; `tabindex` parks at `-1`. On a custom host (`native: false`), it compiles `role="link"` (when `href` is declared), `tabindex` (`0` enabled, `-1` disabled), and synthesizes a cancelable click on `Enter` unless the keystroke was already canceled. `Space` commits nothing. An enabled custom click navigates to `href` (`target` honored, `_self` default) after the event bubble settles, so any consumer cancellation still wins; a detached host never navigates. `Ctrl`/`Cmd`/`Shift`-click and real middle-click (`auxclick`, button 1) open `href` in a new tab (`_blank`) unless an explicit `target` says otherwise — matching what a native anchor does. Matching the ambient `linkCtx` URL (or `current: true`) emits `aria-current="page"`. Inside an `aria('pagination')`, a native page link is a tab stop only while it is the current page — the other page links sit at `tabindex="-1"` and are reached with the arrow keys. Custom hosts keep their own `0` / `-1` stop and don't join the rove. The same single-stop rule applies inside an `aria('breadcrumb')` — mark the terminal page `current`. A link carrying `page` writes that position into the enclosing `aria('pagination')` when it activates, on either host, so clicking page 4 moves the run; a link with no `page` commits nothing and never disturbs the position. Middle-click and `Ctrl` / `Cmd` / `Shift` gestures open a tab and deliberately commit no page, since the reader has not left the current one.

:::tip[Disabled links]
Keep the element in the DOM and pass `disabled` rather than swapping `<a>` for a `<span>`. The destination stays discoverable, navigation is blocked, and assistive technologies report the link as unavailable instead of reporting nothing at all.
:::

## Putting It Together

Once your component is wired with `aria('link')`, compose it to build navigation that degrades honestly:

```tsx
<div className="flex flex-col gap-3">
  <Link href="/docs/aria/button">Button documentation</Link>
  <Link href="https://www.w3.org/WAI/ARIA/apg/patterns/" target="_blank">
    WAI-ARIA Authoring Practices
  </Link>
  <Link href="/docs/aria/button" disabled={true}>
    Restricted destination
  </Link>
</div>
```

## Keyboard Navigation

- **Tab**: Focuses the link. Disabled links on either host sit at `tabindex="-1"` and are skipped. Inside a pagination or a breadcrumb, only the current link takes a tab stop.
- **Enter**: Activates the link. Native anchors handle this in the browser; custom hosts receive the polyfill.
- **Space**: Intentionally does nothing — `Space` activates buttons, not links.

## What you get

- **Native-first semantics.** Binds to `<a>` by default, so no redundant `role` is emitted and the browser keeps handling activation.
- **A real disabled state.** Keeps `href`, announces `aria-disabled="true"`, and blocks navigation — the state HTML anchors lack.
- **Current-page announcement.** Matches `href` against the ambient URL, emitting `aria-current="page"`, with a `current` override.
- **Pagination-aware.** A `page` prop commits its position into the enclosing pagination on activation, so prev / next controls and page links share one source of truth.
- **Custom element support.** Compiles `role="link"`, manages `tabindex`, and activates on `Enter` for `<span>` and `<div>` hosts.
- **Browser-accurate keys.** `Enter` activates a link; `Space` deliberately does not.
