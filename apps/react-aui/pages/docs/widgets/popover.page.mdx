# AUI Popover

A shortcuts sheet, a filter form, a small inspector — content that belongs to one button and should appear right beside it. People expect focus to move into it when it opens, `Escape` or a click elsewhere to close it, focus to come back to the button, and the rest of the page to keep working meanwhile.

**AUI Popover** handles all of it. Put it inside the button it belongs to; that button opens it.

:::interactive[Popover demo]

```tsx
import { Button, Popover, Toggle } from '@airlib/react-aui';
import { $bind, mutable, setup, Snippet } from '@airlib/react';

const PopoverDemo = setup(() => {
  const state = mutable({ open: false, dismissable: true, autofocus: true, above: false });

  return () => (
    <div className="demo-button">
      <div className="flex gap-xs w-full flex-wrap">
        <Toggle size="sm" pressed={$bind(state, 'open')}>
          {() => (state.open ? 'Close panel' : 'Open panel')}
        </Toggle>
        <Toggle size="sm" pressed={$bind(state, 'dismissable')}>
          {() => (state.dismissable ? 'Outside click closes' : 'Outside click ignored')}
        </Toggle>
        <Toggle size="sm" pressed={$bind(state, 'autofocus')}>
          {() => (state.autofocus ? 'Focus moves in' : 'Focus stays put')}
        </Toggle>
        <Toggle size="sm" pressed={$bind(state, 'above')}>
          {() => (state.above ? 'Opens above' : 'Opens below')}
        </Toggle>
      </div>
      <div className="aui-card flex flex-wrap gap-lg items-center justify-center p-xl">
        <Snippet>
          {() => (
            <Button>
              Workspace shortcuts
              <Popover
                open={$bind(state, 'open')}
                dismissable={state.dismissable}
                autofocus={state.autofocus}
                yDir={state.above ? 'above' : undefined}
              >
                <span>Find anything</span>
                <span>Save</span>
                <span>Command palette</span>
                <small>Press Escape, or click outside, to close.</small>
              </Popover>
            </Button>
          )}
        </Snippet>
        <Snippet>
          {() => (
            <Button disabled>
              Locked button
              <Popover>Never shown while the button is disabled.</Popover>
            </Button>
          )}
        </Snippet>
      </div>
    </div>
  );
}, 'PopoverDemo');
```

## Usage

### Put it inside its button

Render `Popover` inside the button, link, or toggle that opens it. Clicking that control opens the panel; nothing else needs wiring:

```tsx
import { Button, Popover } from '@airlib/react-aui';
import '@airlib/aui/components/widgets/popover.css';

export const Shortcuts = () => (
  <Button>
    Workspace shortcuts
    <Popover>
      <span>Find anything — ⌘K</span>
      <span>Save — ⌘S</span>
    </Popover>
  </Button>
);
```

Write the content like a small dialog: a heading if it helps, the content, and any controls people need. For a list of commands or options, use [Menu](/docs/widgets/menu) or [Select](/docs/widgets/select) instead — they bring the right keyboard behavior with them.

### Choose how it opens and closes

- **Open on hover or focus** as well as click with `mode={['click', 'hover', 'focus']}`; `delay` holds back hover-opening for a moment.
- **Focus:** opening moves focus into the panel — to a selected or current item if there is one, else the first control, else the panel. Turn `autofocus` off for purely informational panels where moving focus would be noise.
- **Closing:** `Escape` always closes the panel and returns focus to the button. A click outside closes it too, unless `dismissable` is off.
- Nothing is trapped: `Tab` moves on from the panel into the page.
- A disabled button never opens its popover.

### Choose the side

`yDir="above"` opens the panel above its button; `xDir="before"` / `"after"` aligns it to the button's start or end edge. When there's no room, the panel flips to the side that fits:

```tsx
<Button>
  Filters
  <Popover yDir="above" xDir="after">
    <FilterForm />
  </Popover>
</Button>
```

### Open it from your code

The button opens and closes the popover itself. Bind `open` when something else should drive it — a tour step, a first-run hint:

```tsx
const state = mutable({ open: false });

<Button>
  Workspace shortcuts
  <Popover open={$bind(state, 'open')}>…</Popover>
</Button>
```

### Properties

| Prop | Type | Default | Notes |
| --- | --- | --- | --- |
| `open` | `Bindable<boolean>` | `false` | Whether the panel is showing. |
| `mode` | `('click' \| 'hover' \| 'focus' \| 'rove' \| 'combo')[]` | `['click']` | Which gestures on the button open the panel. |
| `delay` | `number` | `0` | Milliseconds hover waits before opening. |
| `dismissable` | `boolean` | `true` | Whether a click outside closes the panel. `Escape` closes it either way. |
| `autofocus` | `boolean` | `true` | Whether opening moves focus into the panel. |
| `xDir` | `'before' \| 'after' \| 'left' \| 'between' \| 'right'` | — | Horizontal alignment to the button. |
| `yDir` | `'top' \| 'bottom' \| 'above' \| 'below' \| 'between'` | — | Which side of the button the panel opens on. |
| `popupRole` | `'dialog' \| 'menu' \| 'tooltip' \| 'listbox'` | `'dialog'` | What the panel is announced as. Set it once; it doesn't change later. |
| `onopen` / `onclose` / `ontoggle` | `(event: CustomEvent<boolean>) => void` | — | Called when the panel opens, closes, or either. |
| `size` / `color` | shared vocabulary | `md` / `primary` | Size and accent of the panel. |
| `className` | `string` | — | Added alongside the built-in classes, or in place of them with `overrides` enabled. |
| `children` | `ReactNode` | — | The panel content. |

### Keyboard

- `Enter` or `Space` on the button opens the panel; focus moves in unless `autofocus` is off.
- `Escape` closes it and returns focus to the button.
- `Tab` moves through the panel's controls and on into the page.
