# AUI Toggle

A toggle is a button that keeps its state: pressed or not, announced as such, and flipped by every activation. Formatting bars, favorite stars, and mute switches are all toggles — anywhere a control stays on after you let go. A pressed toggle takes its color as a solid background with the matching on-color text; unpressed stays a light tint of that color.

Styling is optional. Without AUI CSS the Toggle stays a correct, operable two-state button; with it, the same markup gets the AUI treatment through the full library.

:::interactive[Toggle demo]

```tsx
import { Toggle } from '@airlib/react-aui';
import { HelpIcon } from '@airlib/react-aui/icons';
import { $bind, mutable, setup, Snippet } from '@airlib/react';
import { DemoControl } from '@/components/DemoControl.js';

const ToggleDemo = setup(() => {
  const state = mutable({ pressed: false, size: 'md', color: 'primary', disabled: false });

  return () => (
    <div className="demo-button">
      <DemoControl size={$bind(state, 'size')} color={$bind(state, 'color')} disabled={$bind(state, 'disabled')} />
      <div className="aui-card flex gap-md items-center justify-center p-xl">
        <Snippet>
          {() => (
            <Toggle
              size={state.size}
              color={state.color}
              disabled={state.disabled}
              pressed={$bind(state, 'pressed')}
            >
              {state.pressed ? 'Pressed' : 'Unpressed'}
            </Toggle>
          )}
        </Snippet>
        <Snippet>
          {() => (
            <Toggle
              size={state.size}
              color={state.color}
              disabled={state.disabled}
              pressed={$bind(state, 'pressed')}
            >
              <HelpIcon />
              <span>{state.pressed ? 'Pressed' : 'Unpressed'}</span>
            </Toggle>
          )}
        </Snippet>
        <Snippet>
          {() => (
            <Toggle
              size={state.size}
              color={state.color}
              disabled={state.disabled}
              pressed={$bind(state, 'pressed')}
              className="aui-control-icon"
            >
              <HelpIcon />
            </Toggle>
          )}
        </Snippet>
      </div>
    </div>
  );
}, 'ToggleDemo');
```

## Usage

```tsx
import { Toggle } from '@airlib/react-aui';
import '@airlib/aui/components/widgets/toggle.css';

export const BoldControl = () => <Toggle>Bold</Toggle>;
```

For the full library — tokens, base defaults, every component, and the utilities — load `import '@airlib/aui';` instead. A lone component stylesheet carries only that component's rules.

### Properties

| Prop | Type | Default | Notes |
| --- | --- | --- | --- |
| `pressed` | `Bindable<boolean>` | `false` | Whether the toggle is pressed. Bind it to read and write the state from outside. |
| `value` | `string`, `number` | — | Group membership token; a member derives `pressed` from the shared group value instead. |
| `disabled` | `boolean` | `false` | Locks the toggle; clicks, keys, and writes are refused while locked. |
| `size` | `xs`, `sm`, `md`, `lg`, `xl`, `xxl` | `'md'` | Explicit props win; otherwise the configured default applies. |
| `color` | `primary`, `secondary`, `tertiary`, `error`, `success`, `warning`, `info` | `'primary'` | Same precedence as `size`. |
| `onchange` | `(event: CustomEvent<...>) => void` | — | Fires after each real flip with the new state in `detail`; silent when nothing changes. |
| `className` | `string` | — | Added alongside the built-in classes, or in place of them with `overrides` enabled. |
| `children` | `ReactNode` | — | Toggle label. |
| `ref` | `Ref<HTMLButtonElement>` | — | Access to the underlying button element. |

Set app-wide defaults once instead of repeating props on every toggle:

```tsx
import { configure } from '@airlib/react-aui';

configure({ toggle: { size: 'sm' } });

// Renders small without passing size every time
<Toggle>Save</Toggle>;
```

Your own classes are added next to the built-in ones:

```tsx
// class="aui-control aui-control-md aui-control-primary aui-control-filled aui-toggle aui-toggle-md aui-toggle-primary aui-toggle-filled my-toggle"
<Toggle className="my-toggle">Bold</Toggle>
```

To make `className` replace the built-in classes, turn on `overrides` once in [Theming](/docs/theming#overrides).

Keyboard: `Tab` focuses the toggle, `Space` flips on key-up, `Enter` flips on key-down. The pressed state is announced through `aria-pressed`, and a locked toggle is announced as disabled.

### Sizes

Sizes: `xs`, `sm`, `md`, `lg`, `xl`, `xxl`, default `md`:

```tsx
<Toggle size="sm">Compact</Toggle>
<Toggle size="lg">Spacious</Toggle>
```

### Color Variants

Colors: `primary`, `secondary`, `tertiary`, `error`, `success`, `warning`, `info`, default `primary`:

```tsx
<Toggle color="error">Alarmed</Toggle>
<Toggle color="success">Synced</Toggle>
```
