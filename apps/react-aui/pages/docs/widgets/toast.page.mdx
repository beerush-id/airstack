# AUI Toast

"Draft saved", "Upload failed — retrying", "Copied to clipboard" — some news deserves a moment of attention, not an interruption. A toast has to announce itself to screen readers, go away on its own, wait while someone is reading or hovering it, and close when asked — exactly once.

**AUI Toast** is that message. You decide where toasts live and when one is added; each toast handles its own lifetime and tells you when it's done.

:::interactive[Toast demo]

```tsx
import { Button, Toast, ToastClose } from '@airlib/react-aui';
import { For, mutable, setup } from '@airlib/react';

const LIFETIME = 6000;

const ToastDemo = setup(() => {
  const state = mutable({
    toasts: [] as { id: number; text: string; color?: string; critical?: boolean; sticky?: boolean }[],
  });

  let seed = 0;

  const add = (text: string, options: { color?: string; critical?: boolean; sticky?: boolean } = {}) => {
    state.toasts = [...state.toasts, { id: ++seed, text, ...options }];
  };

  const remove = (id: number) => {
    state.toasts = state.toasts.filter((entry) => entry.id !== id);
  };

  return () => (
    <div className="demo-button">
      <div className="flex gap-xs w-full flex-wrap">
        <Button size="sm" onClick={() => add('Draft saved')}>
          Save draft
        </Button>
        <Button size="sm" color="success" onClick={() => add('Invoice sent', { color: 'success' })}>
          Send invoice
        </Button>
        <Button size="sm" color="error" onClick={() => add('Upload failed — retrying', { critical: true })}>
          Fail an upload
        </Button>
        <Button size="sm" variant="tonal" onClick={() => add('Pinned until closed', { sticky: true })}>
          Pin a message
        </Button>
      </div>
      <div className="aui-card flex flex-col gap-md p-xl" style={{ minHeight: '9rem' }}>
        <div className="flex flex-col gap-sm" role="region" aria-label="Notifications">
          <For each={() => state.toasts}>
            {(entry) => (
              <Toast
                color={entry.color}
                critical={entry.critical}
                duration={entry.sticky ? undefined : LIFETIME}
                ondismiss={() => remove(entry.id)}
              >
                <span>{entry.text}</span>
                <ToastClose aria-label="Dismiss" />
              </Toast>
            )}
          </For>
        </div>
      </div>
    </div>
  );
}, 'ToastDemo');
```

## Usage

### Show a message

Keep your toasts in a list, render one `Toast` per message, and take it out of the list when it reports `ondismiss`. `duration` is how long it stays, in milliseconds:

```tsx
import { Toast, ToastClose } from '@airlib/react-aui';
import '@airlib/aui/components/widgets/toast.css';

export const SavedToast = ({ onDone }: { onDone: () => void }) => (
  <Toast duration={6000} ondismiss={onDone}>
    <span>Draft saved</span>
    <ToastClose aria-label="Dismiss" />
  </Toast>
);
```

- **`ToastClose`** without children shows a close glyph; give it an `aria-label` in your users' language, since nothing is named for you. Pass children for a text button such as "Undo".
- The toast never removes itself from your page — `ondismiss` is your cue to drop it from your list, so where toasts stack and how they animate stay yours.

### How long it stays

- With `duration`, it closes on its own after that many milliseconds. Hovering it or moving focus into it pauses the countdown; leaving resumes it.
- Without `duration`, it stays until it's closed.
- Closing by timeout, by `ToastClose`, or from your code all end the same way: `ondismiss` fires once.

### How loud it is

- A normal toast is announced politely, after whatever the screen reader is saying.
- **`critical`** announces immediately, interrupting — use it for failures people must act on. A critical toast also takes the error look.

### How it looks

By default a toast is a neutral dark snackbar that stands out on any page. Give it a `color` to tint it with that color's container — `success` for a completed action, `warning` for something to check:

```tsx
<Toast color="success" duration={6000} ondismiss={onDone}>
  <span>Invoice sent</span>
  <ToastClose aria-label="Dismiss" />
</Toast>
```

`size` on the toast also sizes its close button.

### Properties

`Toast`:

| Prop | Type | Default | Notes |
| --- | --- | --- | --- |
| `duration` | `number` | — | Milliseconds until it closes on its own. Omit it to keep the toast until closed. |
| `critical` | `boolean` | `false` | Announce immediately and take the error look. |
| `ondismiss` | `(event: CustomEvent<void>) => void` | — | Called once when the toast closes, for any reason. `event.target` is the toast. |
| `color` | `primary`, `secondary`, `tertiary`, `error`, `success`, `warning`, `info` | — | Tints the toast; without it the toast is neutral. |
| `size` | shared size | `md` | Also sizes the close button. |
| `className` | `string` | — | Added alongside the built-in classes, or in place of them with `overrides` enabled. |
| `children` | `ReactNode` | — | The message and, usually, a `ToastClose`. |

`ToastClose`:

| Prop | Type | Default | Notes |
| --- | --- | --- | --- |
| `children` | `ReactNode` | close glyph | Button content; without it, a close glyph that needs your `aria-label`. |
| `aria-label` | `string` | — | The glyph's name for screen readers. |
| `disabled` | `boolean` | `false` | Stops the button from closing the toast. |
| `color` / `variant` | shared vocabulary | toast's action color / `text` | Override the button's look. |
| `className` | `string` | — | Added alongside the built-in classes, or in place of them with `overrides` enabled. |

Put `ToastClose` inside the `Toast` it closes.
