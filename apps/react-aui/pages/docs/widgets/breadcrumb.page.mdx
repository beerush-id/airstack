# AUI Breadcrumb

Deep pages need a way back up: Docs / Widgets / Breadcrumb. A hand-built trail tends to announce every "/" to screen readers, give each crumb its own tab stop, and forget to mark the page the reader is on.

**Breadcrumb** renders the trail from a list of links. Separators stay visual only, the whole trail is one tab stop that lands on the current page, and the arrow keys move along the crumbs.

:::interactive[Breadcrumb demo]

```tsx
import { Breadcrumb } from '@airlib/react-aui';
import { $bind, mutable, setup, Snippet } from '@airlib/react';
import { DemoControl } from '@/components/DemoControl.js';

const BreadcrumbDemo = setup(() => {
  const state = mutable({ size: 'md', color: 'primary', disabled: false });

  return () => (
    <div className="demo-button">
      <DemoControl size={$bind(state, 'size')} color={$bind(state, 'color')} disabled={$bind(state, 'disabled')} />
      <div className="aui-card flex flex-col gap-lg justify-center p-xl">
        <Snippet>
          {() => (
            <Breadcrumb
              label="Documentation trail"
              size={state.size}
              color={state.color}
              links={[
                { href: '#docs', label: 'Docs' },
                { href: '#widgets', label: 'Widgets' },
                { href: '#navigation', label: 'Navigation', disabled: state.disabled },
                { href: '#breadcrumb', label: 'Breadcrumb' },
              ]}
            />
          )}
        </Snippet>
      </div>
    </div>
  );
}, 'BreadcrumbDemo');
```

## Usage

### From a list of links

Pass the trail from the top down as `links`. The last entry is the page the reader is on, so it is marked current for you; mark another entry `current` yourself when the trail continues past the current page:

```tsx
import { Breadcrumb } from '@airlib/react-aui';
import '@airlib/aui/components/widgets/breadcrumb.css';

const TRAIL = [
  { href: '/settings', label: 'Settings' },
  { href: '/settings/team', label: 'Team' },
  { href: '/settings/team/roles', label: 'Roles' },
];

export const SettingsTrail = () => <Breadcrumb label="Settings trail" links={TRAIL} />;
```

A crumb with `disabled` stays visible — readers still see the path — but can't be followed, and keyboard travel steps over it.

### Custom crumbs and separators

Keep `links` and change what renders: the `link` slot fills each crumb, the `separator` slot replaces the "/" between them. Separators remain silent to screen readers whatever you put there:

```tsx
<Breadcrumb label="Settings trail" links={TRAIL}>
  <Breadcrumb.Snippet for="separator">{() => '›'}</Breadcrumb.Snippet>
  <Breadcrumb.Snippet for="link">{(entry) => entry.label.toUpperCase()}</Breadcrumb.Snippet>
</Breadcrumb>
```

### Composing the trail yourself

When crumbs come from different places, place [Link](/docs/widgets/link) elements with a `BreadcrumbSeparator` between them, and mark the reader's page `current`:

```tsx
import { Breadcrumb, BreadcrumbSeparator, Link } from '@airlib/react-aui';

<Breadcrumb label="Settings trail">
  <Link href="/settings">Settings</Link>
  <BreadcrumbSeparator />
  <Link href="/settings/team">Team</Link>
  <BreadcrumbSeparator />
  <Link href="/settings/team/roles" current>Roles</Link>
</Breadcrumb>
```

`BreadcrumbSeparator` shows "/" unless you give it children. Without a `current` crumb, `Tab` skips the trail entirely, so composed trails should always mark one.

### Style it once

`size` and `color` on the Breadcrumb reach every crumb. See [Style a composite once](/docs/theming#style-a-composite-once).

### Properties

| Prop | Type | Default | Notes |
| --- | --- | --- | --- |
| `links` | `LinkEntry[]` | — | `{ href, label, current?, disabled? }` per crumb, top of the hierarchy first. |
| `label` | `string` | `'Breadcrumbs'` | The landmark's name for screen readers. |
| `size` | `xs`, `sm`, `md`, `lg`, `xl`, `xxl` | `'md'` | Type size and height of the trail. |
| `color` | `primary`, `secondary`, `tertiary`, `error`, `success`, `warning`, `info` | `'primary'` | Hover color of the ancestor crumbs. |
| `className` | `string` | — | Added alongside the built-in classes, or in place of them with `overrides` enabled. |
| `children` | `ReactNode` | — | Your own links and separators, when you compose instead of passing `links`. |
| `ref` | `Ref<HTMLElement>` | — | Access to the landmark element. |

Slots: `link` — `(entry: LinkEntry) => ReactNode`, the content of each crumb; `separator` — `() => ReactNode`, the mark between crumbs.

`BreadcrumbSeparator` takes `className` and `children` (the mark to show).

## Keyboard

`Tab` lands on the current crumb and leaves the trail from there. `ArrowRight` / `ArrowLeft` move to the next / previous crumb, skipping disabled ones and wrapping at the ends. `Home` / `End` jump to the first and last crumb. `Enter` follows the focused crumb.
