# AUI Code Input

Verification codes and PINs read best as separate boxes, but people expect them to behave like one field: typing moves to the next box, pasting a code fills them all, the phone's SMS autofill just works, and tabbing past it doesn't stop six times. Code Input gives you the boxes and that behavior, holds the code as one string, and tells you the moment it's complete.

:::interactive[Code input demo]

```tsx
import { CodeInput, Toggle } from '@airlib/react-aui';
import { $bind, mutable, setup, Snippet } from '@airlib/react';
import { DemoControl } from '@/components/DemoControl.js';

const CodeInputDemo = setup(() => {
  const state = mutable({ code: '42', backup: 'A9', size: 'md', color: 'primary', disabled: false, readonly: false });

  return () => (
    <div className="demo-button">
      <DemoControl size={$bind(state, 'size')} color={$bind(state, 'color')} disabled={$bind(state, 'disabled')}>
        <Toggle size="sm" pressed={$bind(state, 'readonly')}>
          {() => (state.readonly ? 'Set Editable' : 'Set Read-only')}
        </Toggle>
      </DemoControl>
      <div className="aui-card flex flex-col gap-lg p-xl">
        <Snippet>
          {() => (
            <CodeInput
              label="Verification code"
              value={$bind(state, 'code')}
              size={state.size}
              color={state.color}
              disabled={state.disabled}
              readonly={state.readonly}
            />
          )}
        </Snippet>
        <Snippet>
          {() => (
            <CodeInput
              label="Backup code"
              length={4}
              kind="alphanumeric"
              value={$bind(state, 'backup')}
              variant="outlined"
              size={state.size}
              color={state.color}
              disabled={state.disabled}
              readonly={state.readonly}
            />
          )}
        </Snippet>
        <Snippet>
          {() => <span>{state.code.length === 6 ? `${state.code} — complete` : `${state.code.length} of 6 digits`}</span>}
        </Snippet>
      </div>
    </div>
  );
}, 'CodeInputDemo');
```

## Usage

### The simple form

Name it and bind the code. It renders six cells by default; `length` changes the count:

```tsx
import { CodeInput } from '@airlib/react-aui';
import { $bind, mutable, setup } from '@airlib/react';
import '@airlib/aui/components/widgets/code-input.css';

const Verify = setup(() => {
  const form = mutable({ code: '' });

  return () => <CodeInput label="Verification code" value={$bind(form, 'code')} />;
}, 'Verify');
```

The `label` also names every cell for screen readers — "Verification code, character 2 of 6" — so people always know where they are.

### Act when the code is complete

`oncomplete` fires as soon as the last character lands, which is the moment to verify. `onchange` fires when the user leaves the field with a changed code — the right hook for form state:

```tsx
<CodeInput label="Verification code" value={$bind(form, 'code')} oncomplete={(event) => verify(event.detail)} />
```

### Allowed characters

`kind="numeric"` (default) accepts digits only and opens the number pad on phones; `kind="alphanumeric"` also accepts letters. Anything else is ignored as it's typed or pasted:

```tsx
<CodeInput label="Backup code" length={8} kind="alphanumeric" value={$bind(form, 'backup')} />
```

### Paste and autofill

Pasting a code into any cell spreads it across the cells that follow, and the phone's one-time-code autofill fills the whole field — no extra setup.

### Locking

`readonly` shows the code for copying while refusing edits; `disabled` locks every cell and takes the field out of the tab order.

### Your own cells

To lay the cells out yourself — say, a dash after the third — compose them. Each `CodeInputCell` takes its position:

```tsx
import { CodeInput, CodeInputCell } from '@airlib/react-aui';

<CodeInput label="Verification code" length={6} value={$bind(form, 'code')}>
  <CodeInputCell index={0} />
  <CodeInputCell index={1} />
  <CodeInputCell index={2} />
  <span aria-hidden="true">–</span>
  <CodeInputCell index={3} />
  <CodeInputCell index={4} />
  <CodeInputCell index={5} />
</CodeInput>;
```

Provide one cell for every position up to `length`.

### Style it once

`size`, `color`, and `variant` (`filled`, `tonal`, `outlined`) go on the Code Input and reach every cell. See [Style a composite once](/docs/theming#style-a-composite-once).

### Properties

#### CodeInput

| Prop | Type | Default | Notes |
| --- | --- | --- | --- |
| `value` | `Bindable<string>` | `''` | The code as one string. |
| `length` | `number` | `6` | Number of characters, and of cells in the simple form. |
| `kind` | `'numeric'`, `'alphanumeric'` | `'numeric'` | Which characters are accepted. |
| `label` | `string` | — | Names the field and every cell. |
| `readonly` | `boolean` | `false` | Focusable and copyable, not editable. |
| `disabled` | `boolean` | `false` | Locks every cell. |
| `size` | `xs`–`xxl` | `'md'` | Reaches every cell. |
| `variant` | `filled`, `tonal`, `outlined` | `'filled'` | |
| `color` | `primary`, `secondary`, `tertiary`, `error`, `success`, `warning`, `info` | `'primary'` | |
| `oninput` | `(event: CustomEvent<string>) => void` | — | Every edit that changes the code. |
| `onchange` | `(event: CustomEvent<string>) => void` | — | The changed code, when the user leaves the field. |
| `oncomplete` | `(event: CustomEvent<string>) => void` | — | The full code, as soon as it reaches `length`. |
| `children` | `ReactNode` | — | Your own cells; leave empty for the simple form. |
| `className` | `string` | — | Added next to the built-in classes, or replaces them with [`overrides`](/docs/theming#overrides). |

#### CodeInputCell

Takes `index` (its position, from `0`) plus `className` and any `input` attribute. A cell's own `size`, `color`, or `variant` wins over the Code Input's.

## Keyboard

The whole field is one tab stop. Typing advances to the next cell; `ArrowLeft` / `ArrowRight` move between filled cells, `Home` / `End` jump to the start or the end of the code. `Backspace` deletes the character before the caret and moves back; `Delete` removes the current one in place.
