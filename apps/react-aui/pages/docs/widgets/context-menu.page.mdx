# AUI Context Menu

Rows in a list, files in a tree, cards on a board — people expect a right-click to offer the commands for that thing, right where they clicked. Keyboard users need the same menu without a mouse, and everyone expects it to close on `Escape`, on a click elsewhere, or once a command runs.

**AUI Context Menu** wraps the area that owns the commands. A right-click opens the menu at the pointer; `Shift + F10` opens it from the keyboard.

:::interactive[Context Menu demo]

```tsx
import { ContextMenu } from '@airlib/react-aui';
import { mutable, setup, Snippet } from '@airlib/react';

const STEP_ACTIONS = { duplicate: 'Duplicate step', rename: 'Rename…', archive: 'Archive' };
const STEP_ROWS = ['Ship the docs', 'Publish the release notes', 'Announce in the forum'];

const ContextMenuDemo = setup(() => {
  const state = mutable({ last: 'Right-click a step, or focus one and press Shift + F10' });

  return () => (
    <div className="aui-card flex flex-col gap-md p-xl">
      <ContextMenu
        label="Step actions"
        items={STEP_ACTIONS}
        oncommand={(event) => (state.last = `Picked: ${STEP_ACTIONS[event.detail]}`)}
      >
        <div className="flex flex-col gap-xs">
          {STEP_ROWS.map((row) => (
            <div key={row} tabIndex={0}>
              {row}
            </div>
          ))}
        </div>
      </ContextMenu>
      <Snippet>{() => <span>{state.last}</span>}</Snippet>
    </div>
  );
}, 'ContextMenuDemo');
```

## Usage

### Wrap the target and give it your commands

The children are the area people right-click. Pass `items` and a `label`, and listen for the picked command's `name`:

```tsx
import { ContextMenu } from '@airlib/react-aui';
import '@airlib/aui/components/widgets/context-menu.css';

export const FileRow = ({ file, onAction }: { file: string; onAction: (name: string) => void }) => (
  <ContextMenu
    label={`Actions for ${file}`}
    items={{ open: 'Open', rename: 'Rename…', delete: 'Delete' }}
    oncommand={(event) => onAction(event.detail)}
  >
    <div tabIndex={0}>{file}</div>
  </ContextMenu>
);
```

Keep something focusable inside the target — a row with `tabIndex={0}`, a link, a button — so keyboard users can reach it and press `Shift + F10`.

`items` takes a name-to-label map, or an array of `{ name, label, disabled }` when a command needs to be disabled.

### Change what a row shows

Keep `items` and supply each row's content through the `item` slot — an icon, a shortcut hint:

```tsx
<ContextMenu label="Step actions" items={STEP_ACTIONS}>
  <ContextMenu.Snippet for="item">{(entry) => <span>{entry.label}</span>}</ContextMenu.Snippet>
  <StepList />
</ContextMenu>
```

### Build the menu from parts

When the menu mixes kinds of rows — toggles, exclusive options, separators — put a `ContextMenuPanel` after the target and fill it with the same rows a [Menu](/docs/widgets/menu) uses:

:::interactive[Every kind of row]

```tsx
import { ContextMenu, ContextMenuPanel, Divider, MenuItem, MenuItemCheckbox, MenuItemGroup, MenuItemRadio } from '@airlib/react-aui';
import { $bind, mutable, setup, Snippet } from '@airlib/react';

const BoardMenuDemo = setup(() => {
  const state = mutable({ timestamps: true, sort: 'manual', last: 'No command yet' });

  return () => (
    <div className="aui-card flex flex-col gap-md p-xl">
      <ContextMenu label="Board actions" oncommand={(event) => (state.last = `Command: ${event.detail}`)}>
        <div tabIndex={0} className="p-lg">
          Right-click anywhere on the board
        </div>
        <ContextMenuPanel>
          <MenuItem name="new-card">New card</MenuItem>
          <MenuItem name="paste" disabled>
            Paste
          </MenuItem>
          <Divider />
          <MenuItemCheckbox checked={$bind(state, 'timestamps')}>Show timestamps</MenuItemCheckbox>
          <Divider />
          <MenuItemGroup label="Sort by" value={$bind(state, 'sort')}>
            <MenuItemRadio value="manual">Manual order</MenuItemRadio>
            <MenuItemRadio value="recent">Recent changes</MenuItemRadio>
          </MenuItemGroup>
        </ContextMenuPanel>
      </ContextMenu>
      <Snippet>{() => <span>{state.last} · timestamps {state.timestamps ? 'on' : 'off'} · sort {state.sort}</span>}</Snippet>
    </div>
  );
}, 'BoardMenuDemo');
```

### Open it from your code

Bind `open` when something else should open the menu — a "more" button on a touch screen, for example. Every way of closing writes the same `open`:

```tsx
<ContextMenu label="Step actions" items={STEP_ACTIONS} open={$bind(state, 'open')}>
  <StepList />
</ContextMenu>
```

### Style it once

`size`, `color`, and `variant` on `ContextMenu` reach the popup and every row; a row's own prop wins. See [Style a composite once](/docs/theming#style-a-composite-once).

### Properties

`ContextMenu`:

| Prop | Type | Default | Notes |
| --- | --- | --- | --- |
| `label` | `string` | — | The menu's name, announced when it opens. |
| `items` | `Record<string, string>` or `Array<{ name, label?, disabled? }>` | — | Renders the popup with one row per command after your target. |
| `oncommand` | `(event: CustomEvent<string>) => void` | — | Receives the picked command's `name`. |
| `open` | `Bindable<boolean>` | `false` | Whether the menu is showing. |
| `disabled` | `boolean` | `false` | Stops the menu from opening. |
| `onopen` / `onclose` | `(event: CustomEvent<boolean>) => void` | — | Called after the menu opens or closes. |
| `size` / `color` / `variant` | shared vocabulary | `md` / `primary` / — | Reach the popup and every row. |
| `className` | `string` | — | Added alongside the built-in classes, or in place of them with `overrides` enabled. |
| `children` | `ReactNode` | — | The target area, plus `ContextMenuPanel` when composing by hand. |

Slot (with `items`): `item(entry)` for each row's content.

Parts: `ContextMenuPanel` (style props, `children`) holds the rows; the rows are [Menu](/docs/widgets/menu)'s `MenuItem`, `MenuItemCheckbox`, `MenuItemGroup`, and `MenuItemRadio`.

### Keyboard

- `Shift + F10` (or the context-menu key) on a focused element inside the target opens the menu.
- `↑` / `↓` move between rows; typing a letter jumps to the next row that starts with it.
- `Enter` or `Space` runs a command and closes the menu, or flips a checkbox row.
- `Escape` closes the menu and returns focus to where it was.
