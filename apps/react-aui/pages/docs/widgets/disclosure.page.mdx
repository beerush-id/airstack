# AUI Disclosure

"Show more", shipping details under a price, advanced options under a form: one section that people open only when they want it. Doing it by hand means telling screen readers whether the section is open, keeping the header and the section linked, and making the header work with `Enter` and `Space` as well as a click.

**AUI Disclosure** does all of that. Give it a label and the content to hide, and bind whether it is open when the rest of your screen needs to know.

:::interactive[Disclosure demo]

```tsx
import { Disclosure, Readout } from '@airlib/react-aui';
import { $bind, mutable, setup, Snippet } from '@airlib/react';
import { DemoControl } from '@/components/DemoControl.js';
import { GlassStage } from '@/components/GlassStage.js';

const DisclosureDemo = setup(() => {
  const state = mutable({ open: true, size: 'md', color: 'primary', disabled: false });

  return () => (
    <div className="demo-button">
      <DemoControl size={$bind(state, 'size')} color={$bind(state, 'color')} disabled={$bind(state, 'disabled')} />
      <Snippet>
        {() => (
          <GlassStage>
            <div className="flex flex-col gap-md">
              <Disclosure
                label="Shipping details"
                expanded={$bind(state, 'open')}
                size={state.size}
                color={state.color}
                disabled={state.disabled}
              >
                Arrives in 2–3 business days, tracked door to door.
              </Disclosure>
              <Disclosure label="Return policy" size={state.size} color={state.color} disabled={state.disabled}>
                Send it back within 30 days for a full refund.
              </Disclosure>
            </div>
          </GlassStage>
        )}
      </Snippet>
      <Snippet>{() => <Readout label="Shipping details" value={state.open ? 'Open' : 'Closed'} />}</Snippet>
    </div>
  );
}, 'DisclosureDemo');
```

## Usage

### A label and its content

Give the header text as `label`; everything inside becomes the hidden section:

```tsx
import { Disclosure } from '@airlib/react-aui';
import '@airlib/aui/components/widgets/disclosure.css';

export const ShippingDetails = () => (
  <Disclosure label="Shipping details">
    <p>Arrives in 2–3 business days, tracked door to door.</p>
  </Disclosure>
);
```

It starts closed. Bind `expanded` to open it from elsewhere — "Show all details" — or to remember the choice:

```tsx
<Disclosure label="Advanced options" expanded={$bind(prefs, 'showAdvanced')}>
  <AdvancedOptions />
</Disclosure>
```

### Custom header content

When the header needs more than text — an icon, a summary of what is inside — supply it through the `trigger` slot. The chevron and the open/close behavior stay in place:

```tsx
<Disclosure label="Shipping details">
  <Disclosure.Snippet for="trigger">
    {() => (
      <>
        Shipping <span className="muted">· free over €50</span>
      </>
    )}
  </Disclosure.Snippet>
  <ShippingTable />
</Disclosure>
```

### Building from parts

When the header and the section are not next to each other — the header in a card's footer, the section above it — compose the parts:

```tsx
import { Disclosure, DisclosurePanel, DisclosureTrigger } from '@airlib/react-aui';

<Disclosure expanded={$bind(card, 'details')}>
  <DisclosurePanel>
    <OrderLines />
  </DisclosurePanel>
  <DisclosureTrigger>Order details</DisclosureTrigger>
</Disclosure>
```

### Style it once

`size` and `color` on `Disclosure` reach the header; its own prop still wins. An open header takes the color. See [Theming](/docs/theming#style-a-composite-once).

### Properties

`Disclosure`:

| Prop | Type | Default | Notes |
| --- | --- | --- | --- |
| `label` | `string` | — | The header text. Set it and the header and section are rendered for you; leave it out to compose the parts. |
| `expanded` | `Bindable<boolean>` | `false` | Whether the section is open. Bind it to read or change it from outside. |
| `disabled` | `boolean` | `false` | Keeps the section as it is and refuses to open or close. |
| `size` | `xs`–`xxl` | `'md'` | Reaches the header and section. |
| `color` | `primary`, `secondary`, `tertiary`, `error`, `success`, `warning`, `info` | `'primary'` | The color of the open header. |
| `ontoggle` | `(event: CustomEvent<boolean>) => void` | — | The section opened or closed; `detail` is the new state. |
| `className` | `string` | — | Added alongside the built-in classes, or in place of them with `overrides` enabled. |
| `children` | `ReactNode` | — | With `label`: the hidden content. Without it: one `DisclosureTrigger` and one `DisclosurePanel`. |

Slots, used with `label`:

| Slot | Receives | Renders |
| --- | --- | --- |
| `trigger` | — | What the header shows, in place of `label`. |

Parts, used without `label`:

| Part | Props | Notes |
| --- | --- | --- |
| `DisclosureTrigger` | `disabled` | The header that opens and closes the section. |
| `DisclosurePanel` | — | The content shown while open. |

Keyboard: the header is a regular stop in the tab order; `Enter` or `Space` opens or closes the section.
