# AUI Select

A select keeps a list out of the way until someone needs it: closed it shows the current choice, open it offers every option. Departure cities, page sizes, and filters are selects — anywhere a full list would crowd the layout. **Select** gives you the trigger, the popup, the options, arrow-key travel, and single or multiple selection from one call with your options.

:::interactive[Select demo]

```tsx
import { Select } from '@airlib/react-aui';
import { $bind, mutable, setup, Snippet } from '@airlib/react';
import { DemoControl } from '@/components/DemoControl.js';

const CITIES = { ams: 'Amsterdam', ber: 'Berlin', cop: 'Copenhagen', dub: 'Dublin', vil: 'Vilnius' };

const SelectDemo = setup(() => {
  const state = mutable({
    city: 'ber',
    stops: ['cop'],
    size: 'md',
    color: 'primary',
    disabled: false,
  });

  return () => (
    <div className="demo-button">
      <DemoControl size={$bind(state, 'size')} color={$bind(state, 'color')} disabled={$bind(state, 'disabled')} />
      <Snippet>
        {() => (
          <div className="aui-card flex flex-wrap gap-md items-center justify-center p-xl">
            <Select
              label="Departure"
              options={CITIES}
              value={$bind(state, 'city')}
              size={state.size}
              color={state.color}
              disabled={state.disabled}
            />
            <Select
              multiple
              placeholder="Add stops"
              options={CITIES}
              value={$bind(state, 'stops')}
              size={state.size}
              color={state.color}
              disabled={state.disabled}
            />
          </div>
        )}
      </Snippet>
      <Snippet>{() => <span>Departure: {state.city} · Stops: {state.stops.join(', ') || 'none'}</span>}</Snippet>
    </div>
  );
}, 'SelectDemo');
```

## Usage

### Pass your options

When your choices are data — a map of codes to names, or a list from the server — hand them to `options` and bind the value:

```tsx
import { Select } from '@airlib/react-aui';
import { $bind, mutable, setup } from '@airlib/react';
import '@airlib/aui/components/widgets/select.css';

const CITIES = { ams: 'Amsterdam', ber: 'Berlin', lis: 'Lisbon' };

export const DeparturePicker = setup(() => {
  const trip = mutable({ from: 'ams' });

  return () => <Select label="Departure" options={CITIES} value={$bind(trip, 'from')} />;
}, 'DeparturePicker');
```

You supply:

- `options` — a `{ key: label }` map, or an array of `{ key, label }` entries when you need a fixed order or labels that repeat. The key is what `value` holds; the label is what people see.
- `value` — the chosen key, or an array of keys with `multiple`. Bind it with `$bind` to read and replace the choice from anywhere.
- `label` — the field name shown inside the trigger, above the choice.
- `placeholder` — what the trigger says while nothing is chosen.

With `multiple`, choosing an option keeps the popup open so several picks take one visit.

### Change what the trigger or a row shows

When a name alone is not enough — a city code in front of the name, a second line, an icon — keep `options` and supply the content through a slot. The trigger, the popup, and the keyboard stay as they are:

```tsx
<Select options={CITIES} value={$bind(trip, 'from')} label="Departure">
  <Select.Snippet for="trigger">
    {(value) => (typeof value === 'string' ? `${value.toUpperCase()} · ${CITIES[value]}` : 'Choose a city')}
  </Select.Snippet>
  <Select.Snippet for="option">
    {(entry) => (
      <span>
        <b>{entry.key.toUpperCase()}</b> {entry.label}
      </span>
    )}
  </Select.Snippet>
</Select>
```

- `trigger` receives the current value — a key, an array of keys with `multiple`, or `undefined` before the first choice. Render the empty state yourself.
- `option` receives the entry (`{ key, label }`) and the option's live state (`option.selected`), the same shape Combobox and Listbox pass, and renders inside that row; the check mark and selection behavior stay.

### Compose the parts

When the popup needs content that is not an option list — mixed rows, rows from several sources, a header — build the select from its parts. They find each other on their own; there are no ids or open state to pass around:

```tsx
import { Select, SelectOption, SelectPanel, SelectTrigger } from '@airlib/react-aui';

<Select value={$bind(trip, 'from')}>
  <SelectTrigger label="Departure" placeholder="Choose a city" />
  <SelectPanel>
    <SelectOption value="ams">Amsterdam</SelectOption>
    <SelectOption value="ber">Berlin</SelectOption>
    <SelectOption value="lis" disabled>
      Lisbon (sold out)
    </SelectOption>
  </SelectPanel>
</Select>
```

The trigger shows the chosen option's text on its own; pass children to `SelectTrigger` only to replace it.

## Style it once

Set `size`, `color`, and `variant` on `Select` and the trigger, the popup, and every option follow; a part's own prop still wins. The trigger is a field, so it takes `filled`, `tonal`, or `outlined`. See [Styling a composite](/docs/theming#style-a-composite-once).

```tsx
<Select options={CITIES} size="sm" color="tertiary" variant="outlined" />
```

## Properties

### Select

| Prop | Type | Default | Notes |
| --- | --- | --- | --- |
| `options` | `{ [key]: label }`, `Array<{ key, label? }>` | — | Renders the trigger and one option per entry. |
| `value` | `Bindable<string \| string[]>` | — | The chosen key, or keys with `multiple`. |
| `multiple` | `boolean` | `false` | Allows several choices; picking keeps the popup open. |
| `label` | `string` | — | Field name shown inside the trigger. |
| `placeholder` | `string` | — | Trigger text while nothing is chosen. |
| `open` | `Bindable<boolean>` | `false` | Popup visibility, if you need to open or close it yourself. |
| `disabled` | `boolean` | `false` | Locks opening and choosing. |
| `required` | `boolean` | `false` | A choice must stay selected. |
| `size` | `xs`–`xxl` | `'md'` | Reaches the trigger, popup, and options. |
| `variant` | `filled`, `tonal`, `outlined` | `'filled'` | The trigger's surface. |
| `color` | `primary`, `secondary`, `tertiary`, `error`, `success`, `warning`, `info` | `'primary'` | Trigger, focus, and selected rows. |
| `onchange` | `(event: CustomEvent<string \| string[] \| undefined>) => void` | — | After a person commits a choice. |
| `onopen` / `onclose` | `(event: CustomEvent<boolean>) => void` | — | When the popup opens or closes. |
| `className` | `string` | — | Added to the built-in classes on the composed root. |
| `children` | parts, slots | — | `Select.Snippet` slots with `options`, or the parts below. |

### Parts

| Part | Props | Notes |
| --- | --- | --- |
| `SelectTrigger` | `label`, `placeholder`, `disabled`, `size`, `color`, `variant`, `children` | The button that shows the choice and opens the popup. |
| `SelectPanel` | `size`, `color`, `children` | The popup holding the options. |
| `SelectOption` | `value` (required), `disabled`, `size`, `color`, `children` | One choice; its children are the row content. |

Set app-wide defaults once with `configure({ select: { size: 'sm' } })`, or per part with `selectTrigger`, `selectPanel`, and `selectOption`.

## Keyboard

`Enter`, `Space`, or the arrow keys open the popup from the trigger. Arrows move through the options without choosing; `Enter` or `Space` chooses; typing jumps to the next option starting with those letters. `Escape` and a click outside close the popup and return focus to the trigger.
