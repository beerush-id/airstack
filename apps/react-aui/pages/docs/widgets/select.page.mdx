# Maui Select

A select is an option list collapsed behind a trigger: closed it shows one value, open it offers every choice. Country pickers, per-page counts, and city departures are all selects — anywhere a list would eat the layout it sits behind a button instead.

Styling is optional. Without Material CSS the Select stays a correct, operable combobox; with it, the same markup gets the Material treatment through either the full-library or the selective import.

:::interactive[Select demo]

```tsx
import { Select, SelectOption, SelectPanel, SelectTrigger, Toggle } from '@airlib/react-aui';
import { $bind, mutable, setup, Snippet } from '@airlib/react';
import { DemoControl } from '@/components/DemoControl.js';

const CITY_LABELS = {
  ams: 'Amsterdam',
  ber: 'Berlin',
  cop: 'Copenhagen',
  dub: 'Dublin',
  vil: 'Vilnius',
};

const SelectDemo = setup(() => {
  const state = mutable({
    city: 'ber',
    stops: ['cop'],
    size: 'md',
    variant: 'filled',
    color: 'primary',
    disabled: false,
  });

  return () => (
    <div className="demo-button">
      <DemoControl size={$bind(state, 'size')} color={$bind(state, 'color')} variant={$bind(state, 'variant')} disabled={$bind(state, 'disabled')} />
      <div className="aui-card flex gap-md items-center justify-center p-xl">
        <Snippet>
          {() => (
            <Select
              options={CITY_LABELS}
              value={$bind(state, 'city')}
              size={state.size}
              variant={state.variant}
              color={state.color}
              disabled={state.disabled}
              placeholder="Select city"
            />
          )}
        </Snippet>
        <Snippet>
          {() => (
            <Select
              options={CITY_LABELS}
              multiple
              value={$bind(state, 'stops')}
              size={state.size}
              variant={state.variant}
              color={state.color}
              disabled={state.disabled}
              placeholder="Select stops"
            />
          )}
        </Snippet>
      </div>
    </div>
  );
}, 'SelectDemo');
```

## Usage

```tsx
import { Select, SelectOption, SelectPanel, SelectTrigger } from '@airlib/react-aui';
import '@airlib/aui/widgets/select.css';

const CITY_LABELS = { ams: 'Amsterdam', ber: 'Berlin' };

export const DeparturePicker = () => (
  <Select labels={CITY_LABELS} value="ams">
    <SelectTrigger />
    <SelectPanel>
      <SelectOption value="ams">Amsterdam</SelectOption>
      <SelectOption value="ber">Berlin</SelectOption>
    </SelectPanel>
  </Select>
);
```

For the full library instead of the selective import, load `import '@airlib/aui';`. Both modes look the same.

The `labels` map turns tokens into trigger text — without it the trigger has nothing to show. A commit in single mode closes the popup; in `multiple` mode it stays open so a picker that takes several values never slams shut mid-choice.

### Properties

Select (root) holds the value and the popup visibility:

| Prop | Type | Default | Notes |
| --- | --- | --- | --- |
| `value` | `Bindable<string \| string[]>` | — | One token, or an array with `multiple`. Bind it to read and replace the selection from outside. |
| `open` | `Bindable<boolean>` | `false` | Popup visibility. Bind it to move the trigger and panel from outside. |
| `multiple` | `boolean` | `false` | Takes an array `value`; commits keep the popup open. |
| `disabled` | `boolean` | `false` | Locks toggling and committing across the whole select. |
| `required` | `boolean` | `false` | Declares a non-empty selection requirement. |
| `labels` | `Record<string, string>` | — | Token-to-label map the trigger reads at creation. |
| `size` | `xs`, `sm`, `md`, `lg`, `xl`, `xxl` | `'lg'` | Explicit props win; otherwise the configured default applies. |
| `variant` | `filled`, `outlined` | `'outlined'` | Same precedence as `size`. |
| `color` | `primary`, `secondary`, `tertiary`, `error`, `success`, `warning`, `info` | `'primary'` | Same precedence as `size`; drives the trigger text, indicator, and caret. |
| `onchange` | `(event: CustomEvent<...>) => void` | — | Fires with the whole value once a member commit reaches the root. |
| `className` | `string` | — | Added alongside the built-in classes by default; replaces them in replacement mode. |
| `children` | `ReactNode` | — | Trigger, panel, and options. |
| `ref` | `Ref<HTMLDivElement>` | — | Access to the root element. |

SelectTrigger (combobox face), SelectPanel (popup listbox), and SelectOption (selection member) take `id`, `disabled` where applicable, `value` (options only, required), `className`, and children. Options render their children as the row content; the trigger renders the current choice from `labels`.

Set app-wide defaults once instead of repeating props on every select:

```tsx
import { configure } from '@airlib/react-aui';

configure({ select: { size: 'sm' } });
```

Your own classes are added next to the built-in ones:

```tsx
// class="maui-select maui-select-lg maui-select-outlined maui-select-primary my-select"
<Select className="my-select" labels={CITY_LABELS}>
```

Replacement mode renders only your classes — the select keeps working exactly the same:

```tsx
import { configure } from '@airlib/react-aui';

configure({ overrides: true });

// class="my-select"
<Select className="my-select" labels={CITY_LABELS}>
```

Keyboard: `Enter` or `Space` toggles the popup, arrows open it while closed and rove the panel without committing, `Enter` commits the focused option, `Escape` closes and returns focus to the trigger. Dismissal by outside press returns focus the same way.

### Sizes

Sizes: `xs`, `sm`, `md`, `lg`, `xl`, `xxl`, default `lg` — carried by the trigger:

```tsx
<Select labels={CITY_LABELS} size="sm">
```

### Variants

Variants: `filled`, `outlined`, default `outlined`:

```tsx
<Select labels={CITY_LABELS} variant="outlined">
```

### Color Variants

Colors: `primary`, `secondary`, `tertiary`, `error`, `success`, `warning`, `info`, default `primary` — carried by the trigger text, indicator, and caret, while the popup stays neutral:

```tsx
<Select labels={CITY_LABELS} color="error">
```
