# AUI Card

Dashboards, product grids, and settings pages are made of cards: a picture, a heading, a line of context, and the buttons that act on it. The hard part is not the box — it is keeping the pieces in the same order and spacing everywhere, and making each card announce itself by its heading so a screen reader user can tell twenty cards apart.

Card gives you that unit from two props, keeps the spacing on the shared scale, and names the card by its title for you.

:::interactive[Card demo]

```tsx
import { Button, Card } from '@airlib/react-aui';
import { $bind, mutable, setup, Snippet } from '@airlib/react';
import { DemoControl } from '@/components/DemoControl.js';

const CardDemo = setup(() => {
  const state = mutable({ size: 'md', color: 'primary', variant: 'filled', disabled: false });

  return () => (
    <div className="demo-button">
      <DemoControl size={$bind(state, 'size')} color={$bind(state, 'color')} variant={$bind(state, 'variant')} disabled={$bind(state, 'disabled')} />
      <Snippet>
        {() => (
          <div className="demo-stage grid grid-cols-2 gap-md">
            <Card
              title="Team offsite"
              description="Rome · 12–14 November · 6 travelers"
              size={state.size}
              color={state.color}
              variant={state.variant}
            >
              <p>Workshops on day one, the city on day two. Evenings stay free.</p>
              <Card.Snippet for="actions">
                {() => (
                  <>
                    <Button variant="text" size={state.size} color={state.color} disabled={state.disabled}>
                      Share
                    </Button>
                    <Button size={state.size} color={state.color} disabled={state.disabled}>
                      Book
                    </Button>
                  </>
                )}
              </Card.Snippet>
            </Card>
            <Card
              title="Quarterly report"
              description="Revenue up 12%, churn steady."
              size={state.size}
              color={state.color}
              variant={state.variant}
            />
          </div>
        )}
      </Snippet>
    </div>
  );
}, 'CardDemo');
```

## Usage

### Title and description

When the card is a heading, a line of context, and some content, pass `title` and `description` and put the content inside:

```tsx
import { Card } from '@airlib/react-aui';
import '@airlib/aui/components/widgets/card.css';

export const ReportCard = () => (
  <Card title="Quarterly report" description="Revenue up 12%, churn steady.">
    <p>Download the full breakdown before Friday's review.</p>
  </Card>
);
```

The title renders as an `h3` and names the card. When the cards sit under a page heading of a different depth, set `level` (`2`–`6`) so the page outline stays correct. The card renders an `<article>` — right for an entry in a list or feed; use `as="section"` for a region of a page, or `as="div"` when the card is purely visual.

### Slots

Reach for slots when the card needs more than text:

- **`media`** — an image, video, or illustration that bleeds to the card's top and side edges.
- **`header`** — your own heading block in place of `title` and `description`, for a badge next to the title or an avatar beside it. Keep a heading inside so the card stays named.
- **`actions`** — buttons or links, aligned to the end of the card's last row.

```tsx
<Card title="Lisbon loft" description="Sleeps 6 · €180 a night">
  <Card.Snippet for="media">{() => <img src="/loft.jpg" alt="" />}</Card.Snippet>
  <Card.Snippet for="actions">{() => <Button>Reserve</Button>}</Card.Snippet>
</Card>
```

Leave `alt` empty on a media image that only decorates; describe it when it carries information the text does not.

### Building from parts

When the layout is yours — two headers, media in the middle, actions at the top — compose the parts. Each is a plain element with the card's spacing and type; order them however you need:

```tsx
import { Card, CardActions, CardBody, CardDescription, CardHeader, CardMedia, CardTitle } from '@airlib/react-aui';

<Card aria-labelledby="loft-title">
  <CardHeader>
    <CardTitle id="loft-title" level={2}>Lisbon loft</CardTitle>
    <CardDescription>Sleeps 6 · €180 a night</CardDescription>
  </CardHeader>
  <CardMedia><img src="/loft.jpg" alt="" /></CardMedia>
  <CardBody>Ten minutes from the venue on foot.</CardBody>
  <CardActions><Button>Reserve</Button></CardActions>
</Card>
```

Without `title`, name the card yourself with `aria-labelledby`, as above.

### Act on the card

A card stands for one thing — a note, a trip, a file — so the commands for that thing land on it. Put a [Context Menu](/docs/composites/context-menu) or a [Menu](/docs/composites/menu) inside the card, and every command picked from either reaches the card's `oncommand` with the command's name:

```tsx
import { Card, ContextMenu } from '@airlib/react-aui';

<Card title={trip.name} oncommand={(event) => onTripAction(trip, event.detail)}>
  {trip.summary}
  <ContextMenu label={`${trip.name} actions`} items={{ share: 'Share', archive: 'Archive' }} />
</Card>;
```

The handler already knows which card it is, so one handler can serve a whole board of them.

### Style it once

`size` sets the card's padding, spacing, and title size; `color` tints the `tonal` variant; `variant` picks the surface: `filled` (default), `tonal`, or `elevated`. See [Style a composite once](/docs/theming#style-a-composite-once).

## Properties

`Card`:

| Prop | Type | Default | Notes |
| --- | --- | --- | --- |
| `title` | `string` | — | Heading text; also names the card. |
| `description` | `string` | — | One or two lines under the title. |
| `level` | `2`–`6` | `3` | Heading level of the title. |
| `as` | `'article'`, `'section'`, `'div'` | `'article'` | The element the card renders. |
| `size` | `xs`–`xxl` | `'md'` | Padding, spacing, and title size. |
| `color` | `primary`, `secondary`, `tertiary`, `error`, `success`, `warning`, `info` | `'primary'` | Tint for the `tonal` variant. |
| `variant` | `filled`, `tonal`, `elevated` | `'filled'` | The card's surface. |
| `oncommand` | `(event: CustomEvent<string>) => void` | — | A command picked from a context menu or a menu inside the card, with its name. |
| `className` | `string` | — | Added alongside the built-in classes, or in place of them with `overrides` enabled. |
| `children` | `ReactNode` | — | The card's body. |

Slots: `media`, `header`, `actions`. Parts: `CardMedia`, `CardHeader`, `CardTitle` (takes `level`), `CardDescription`, `CardBody`, `CardActions` — each accepts the props of its element.
