# AUI Button

A button is the simplest thing on a page until it sits inside a form: forget `type="button"` and every click submits it. Button gives you safe form defaults on a real `<button>` — a click never submits unless you set `type="submit"` — plus disabled handling that screen readers announce as disabled.

Styling is optional. Without AUI CSS the Button stays a correct, operable button; with it, the same markup gets the AUI treatment through the full library.

:::interactive[Button demo]

```tsx
import { Button } from '@airlib/react-aui';
import { HelpIcon } from '@airlib/react-aui/icons';
import { mutable, setup, $bind, Snippet } from '@airlib/react';
import { DemoControl } from '@/components/DemoControl.js';
import { GlassStage } from '@/components/GlassStage.js';

const ButtonDemo = setup(() => {
  const state = mutable({ count: 0, size: 'md', variant: 'filled', color: 'primary', disabled: false });

  return () => (
    <div className="demo-button">
      <DemoControl size={$bind(state, 'size')} color={$bind(state, 'color')} variant={$bind(state, 'variant')} disabled={$bind(state, 'disabled')} />
      <Snippet>
        {() => (
          <GlassStage>
            <div className="flex gap-md items-center justify-center">
              <Button
                size={state.size}
                variant={state.variant}
                color={state.color}
                disabled={state.disabled}
                onClick={() => {
                  state.count += 1;
                }}
              >
                Clicks: <Snippet>{() => state.count}</Snippet>
              </Button>
              <Button
                size={state.size}
                variant={state.variant}
                color={state.color}
                disabled={state.disabled}
                onClick={() => {
                  state.count += 1;
                }}
              >
                <HelpIcon />
                <span>
                  Clicks: <Snippet>{() => state.count}</Snippet>
                </span>
              </Button>
              <Button
                size={state.size}
                variant={state.variant}
                color={state.color}
                disabled={state.disabled}
                onClick={() => {
                  state.count += 1;
                }}
                className="aui-control-icon"
              >
                <HelpIcon />
              </Button>
            </div>
          </GlassStage>
        )}
      </Snippet>
    </div>
  );
}, 'ButtonDemo');
```

## Usage

```tsx
import { Button } from '@airlib/react-aui';
import '@airlib/aui/components/widgets/button.css';

export const SaveAction = () => <Button>Save</Button>;
```

For the full library — tokens, base defaults, every component, and the utilities — load `import '@airlib/aui';` instead. A lone component stylesheet carries only that component's rules.

### Properties

| Prop | Type | Default | Notes |
| --- | --- | --- | --- |
| `type` | `'button'`, `'submit'`, `'reset'` | `'button'` | What a click does in a form. Leave it and a click never submits. |
| `disabled` | `boolean` | `false` | Locks the button and announces it as disabled. |
| `size` | `xs`, `sm`, `md`, `lg`, `xl`, `xxl` | `'md'` | Explicit props win; otherwise the configured default applies. |
| `variant` | `filled`, `elevated`, `tonal`, `outlined`, `text`, `glass` | `'filled'` | Same precedence as `size`. |
| `color` | `primary`, `secondary`, `tertiary`, `error`, `success`, `warning`, `info` | `'primary'` | Same precedence as `size`. |
| `className` | `string` | — | Added alongside the built-in classes, or in place of them with `overrides` enabled. |
| `children` | `ReactNode` | — | Button label. |
| `ref` | `Ref<HTMLButtonElement>` | — | Access to the underlying button element. |

Set app-wide defaults once instead of repeating props on every button:

```tsx
import { configure } from '@airlib/react-aui';

configure({ button: { size: 'sm' } });

// Renders small without passing size every time
<Button>Save</Button>
```

Your own classes are added next to the built-in ones:

```tsx
// class="aui-control aui-control-md aui-control-primary aui-control-filled aui-button aui-button-md aui-button-primary aui-button-filled my-btn"
<Button className="my-btn">Save</Button>
```

To make `className` replace the built-in classes, turn on `overrides` once in [Theming](/docs/theming#overrides).

Keyboard: `Tab` focuses the button, `Space` activates on key-up, `Enter` activates on key-down. Disabled buttons stay out of the way and go silent to neither sighted nor screen-reader users — they are announced as disabled.

### Sizes

Sizes: `xs`, `sm`, `md`, `lg`, `xl`, `xxl`, default `md`:

```tsx
<Button size="sm">Compact</Button>
<Button size="lg">Spacious</Button>
```

### Variants

Variants: `filled`, `elevated`, `tonal`, `outlined`, `text`, `glass`, default `filled`:

```tsx
<Button variant="filled">High emphasis</Button>
<Button variant="tonal">Medium emphasis</Button>
<Button variant="outlined">Medium emphasis, bordered</Button>
<Button variant="text">Low emphasis</Button>
<Button variant="glass">Over a wallpaper or an image</Button>
```

`glass` is a frosted pane tinted by the color, for a button floating over other content: a desktop, a photo, a video. On another glass surface — a window, the dock, a popup — it keeps its tint and edge but skips a second blur, and when people ask for less transparency it turns solid.

### Color Variants

Colors: `primary`, `secondary`, `tertiary`, `error`, `success`, `warning`, `info`, default `primary`:

```tsx
<Button color="error">Delete</Button>
<Button variant="tonal" color="success">Saved</Button>
```
