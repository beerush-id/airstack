# AUI Tree

A tree presents folders, categories, or organization nodes that expand in place. The hard part is never the nesting — it is **stepping through visible nodes across levels**, **opening a branch and then entering it**, **pairing every child group with its branch**, and **keeping selection coordinated across the whole hierarchy**.

**AUI Tree** does all of that for you, and leaves the markup and the styling entirely yours. The root holds the selection; items declare their own names, and a group inside an item pairs with it on its own.

Styling is optional. Without AUI CSS the Tree stays a correct, operable hierarchy; with it, the same markup gets the AUI treatment through the full library.

## Usage

The root takes the selection; the items and groups describe the hierarchy:

```tsx
import { Tree, TreeGroup, TreeItem } from '@airlib/react-aui';
import '@airlib/aui/components/widgets/tree.css';

export const ProjectFiles = ({ onOpen }: { onOpen: (file: string) => void }) => (
  <Tree label="Project files" value="index.ts" onchange={(event) => onOpen(String(event.detail))}>
    <TreeItem name="src" label="src" expanded={true}>
      <span>src</span>
      <TreeGroup>
        <TreeItem name="index.ts">
          <span>index.ts</span>
        </TreeItem>
      </TreeGroup>
    </TreeItem>
    <TreeItem name="package.json">
      <span>package.json</span>
    </TreeItem>
  </Tree>
);
```

For the full library — tokens, base defaults, every component, and the utilities — load `import '@airlib/aui';` instead. A lone component stylesheet carries only that component's rules.

### The selection

`value` is one node name, or an array when `multiple` is set. A node is selected when its `name` matches:

```tsx
const state = mutable({ files: ['esm', 'types'] });

<Tree label="Export targets" multiple value={$bind(state, 'files')}>
  {/* items */}
</Tree>
```

A node compiles `tabindex="0"` only while it is selected, so a single-select tree holds one stop and a multi-select tree holds one per selected node. With no value the tree has no stop at all, so seed `value` when the tree must be reachable by keyboard.

### Branches and groups

A node is a branch when it takes `expanded` or when a `TreeGroup` mounts inside it. The group marks its parent as a branch, pairs `aria-labelledby` with the item's id, and hides while the branch is collapsed — no ARIA wiring on your side:

```tsx
<TreeItem name="src" label="src" expanded={false}>
  <span>src</span>
  <TreeGroup>
    <TreeItem name="index.ts">
      <span>index.ts</span>
    </TreeItem>
  </TreeGroup>
</TreeItem>
```

A leaf omits `aria-expanded`, so a file is never announced as a folder. Bound `expanded` to follow the controller, and `ontoggle` to hear each open and close:

```tsx
const node = mutable({ open: true });

<TreeItem name="src" label="src" expanded={$bind(node, 'open')} ontoggle={(event) => console.log(event.detail)}>
  {/* label and group */}
</TreeItem>
```

A branch's accessible name is its whole subtree, so pass `label` when the children would otherwise pollute it.

### Keyboard and focus

`manual` defaults to `true`: the arrows move focus without changing the selection, and `Enter`, `Space`, or a click commits. Set `manual={false}` to select whatever focus lands on:

```tsx
<Tree label="Export targets" value="esm" manual={false}>
  {/* items */}
</Tree>
```

### Locking

`disabled` on the root locks selection, expansion, and traversal; `disabled` on a node locks just that node's picks. `required` keeps a single-select tree from clearing its value and announces `aria-required`:

```tsx
<Tree label="Project files" value="index.ts" required>
  {/* items */}
</Tree>
```

### Properties

#### Tree

| Prop | Type | Default | Notes |
| --- | --- | --- | --- |
| `label` | `string` | — | The tree's name. |
| `labelledby` | `string` | — | An element id that names the tree instead. |
| `value` | `Bindable<string \| string[]>` | — | The selected node, or nodes. |
| `multiple` | `boolean` | `false` | Allows more than one selected node. |
| `manual` | `boolean` | `true` | Whether arrows move focus only, or select as they move. |
| `required` | `boolean` | `false` | Refuses an empty single selection. |
| `disabled` | `boolean` | `false` | Locks the whole hierarchy. |
| `id` | `string` | generated | Namespace prefix for node ids. |
| `onchange` | `(event: CustomEvent<string \| string[] \| undefined>) => void` | — | The selection after every commit. |
| `className` | `string` | — | Added alongside the built-in classes, or in place of them with `overrides` enabled. |
| `children` | `ReactNode` | — | Items. |
| `ref` | `Ref<HTMLUListElement>` | — | Access to the tree element. |

#### TreeItem

| Prop | Type | Default | Notes |
| --- | --- | --- | --- |
| `name` | `string` | — | The identity matched against the tree value. |
| `value` | `string` | — | Alias for `name` when `name` is omitted. |
| `label` | `string` | — | The node's accessible name, when its subtree would say too much. |
| `expanded` | `Bindable<boolean>` | — | Marks a branch and holds its state. |
| `selected` | `Bindable<boolean>` | — | The initial hint. |
| `disabled` | `boolean` | `false` | Locks this node's picks and expansion. |
| `ontoggle` | `(event: CustomEvent<boolean>) => void` | — | Each branch open and close. |
| `id` | `string` | generated | The id its child group points at. |

#### TreeGroup

Takes `id`, `label`, and `labelledby` for the rare case you want to name a group yourself; the standard attributes for a `ul` host plus `className` and `ref` come along.

Your own classes are added next to the built-in ones:

```tsx
// class="aui-tree my-tree"
<Tree className="my-tree" label="Project files">
  {/* items */}
</Tree>
```

To make `className` replace the built-in classes, turn on `overrides` once in [Theming](/docs/theming#overrides).

Keyboard: `ArrowDown` and `ArrowUp` visit the next and previous visible enabled node without wrapping, `Home` and `End` reach the first and last, `ArrowRight` opens a closed branch and steps into an open one, `ArrowLeft` closes an open branch or returns to the parent, and `Enter` or `Space` selects.
