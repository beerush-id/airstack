# AUI Tree

File browsers, category pickers, org charts: nested items that open in place. The nesting is the easy part. The hard part is letting the arrow keys walk only what is visible across every level, opening a branch and then stepping into it, telling screen readers which items are folders and which are leaves, and keeping one selection across the whole hierarchy.

**AUI Tree** does all of that. Give it your nested items, bind the selection to your state, and it renders every row, branch, and chevron.

:::interactive[Tree demo]

```tsx
import { Toggle, Tree } from '@airlib/react-aui';
import { $bind, mutable, setup, Snippet } from '@airlib/react';
import { DemoControl } from '@/components/DemoControl.js';

const FILES = [
  {
    name: 'src',
    expanded: true,
    children: [
      { name: 'components', children: [{ name: 'Button.tsx' }, { name: 'Tree.tsx' }] },
      { name: 'index.ts' },
    ],
  },
  { name: 'package.json' },
  { name: 'secrets.env', disabled: true },
];

const TreeDemo = setup(() => {
  const state = mutable({
    file: 'index.ts',
    files: ['Button.tsx', 'index.ts'],
    multiple: false,
    size: 'sm',
    color: 'primary',
    disabled: false,
  });

  return () => (
    <div className="demo-button">
      <DemoControl size={$bind(state, 'size')} color={$bind(state, 'color')} disabled={$bind(state, 'disabled')}>
        <Toggle size="sm" pressed={$bind(state, 'multiple')}>
          {() => (state.multiple ? 'Several' : 'One')}
        </Toggle>
      </DemoControl>
      <div className="aui-card flex flex-col p-xl">
        <Snippet>
          {() => (
            <Tree
              label="Project files"
              items={FILES}
              multiple={state.multiple}
              value={state.multiple ? $bind(state, 'files') : $bind(state, 'file')}
              size={state.size}
              color={state.color}
              disabled={state.disabled}
            />
          )}
        </Snippet>
      </div>
      <Snippet>{() => <span>Selected: {state.multiple ? state.files.join(', ') : state.file}</span>}</Snippet>
    </div>
  );
}, 'TreeDemo');
```

## Usage

### From nested data

Pass your hierarchy as `items`. An entry with `children` is a branch; one without is a leaf. `name` is what the selection holds, `label` what the row shows:

```tsx
import { Tree } from '@airlib/react-aui';
import '@airlib/aui/components/widgets/tree.css';

const CATEGORIES = [
  {
    name: 'clothing',
    label: 'Clothing',
    expanded: true,
    children: [
      { name: 'shirts', label: 'Shirts' },
      { name: 'shoes', label: 'Shoes' },
    ],
  },
  { name: 'gifts', label: 'Gift cards' },
];

export const CategoryPicker = () => <Tree label="Categories" items={CATEGORIES} value={$bind(filter, 'category')} />;
```

Branches start closed unless the entry says `expanded: true`. Disable an entry with `disabled: true`; people can still see it but cannot select or open it.

Seed `value` with a node. The keyboard enters the tree on the selected node, so a tree with nothing selected cannot be reached with `Tab`.

### Choosing several

Set `multiple` to let people pick more than one node; `value` becomes a list of names:

```tsx
<Tree label="Export targets" items={TARGETS} multiple value={$bind(exportJob, 'targets')} />
```

By default the arrow keys only move focus and `Enter`, `Space`, or a click selects. Set `manual={false}` when moving should select, as in a file browser that previews whatever is focused. Set `required` to keep a single-select tree from ending up empty.

### Custom row content

When a row needs more than text — a file icon, a size, a badge — supply it through the `item` slot. Selection, the chevron, and the keyboard stay in place:

```tsx
<Tree label="Project files" items={FILES} value={$bind(editor, 'file')}>
  <Tree.Snippet for="item">
    {(entry) => (
      <>
        <FileIcon name={entry.name} /> {entry.label ?? entry.name}
      </>
    )}
  </Tree.Snippet>
</Tree>
```

### Building from parts

When rows come from several sources or a branch loads its children on demand, compose the parts. Inside a `TreeItem`, everything before the nested `TreeGroup` is the row; the group holds the children and opens and closes with its branch. Give a branch a `label` so screen readers announce its name instead of its whole subtree:

```tsx
import { Tree, TreeGroup, TreeItem } from '@airlib/react-aui';

<Tree label="Project files" value={$bind(editor, 'file')}>
  <TreeItem name="src" label="src" expanded={$bind(folders, 'src')}>
    <span>src</span>
    <TreeGroup>
      <TreeItem name="index.ts">
        <span>index.ts</span>
      </TreeItem>
    </TreeGroup>
  </TreeItem>
  <TreeItem name="package.json">
    <span>package.json</span>
  </TreeItem>
</Tree>
```

Bind a branch's `expanded` to open or close it from elsewhere, and listen to `ontoggle` to load its children the first time it opens.

### Style it once

`size` and `color` on `Tree` reach every row; a row's own prop still wins. Selected rows take the color. See [Theming](/docs/theming#style-a-composite-once).

### Properties

`Tree`:

| Prop | Type | Default | Notes |
| --- | --- | --- | --- |
| `items` | `Array<{ name, label?, disabled?, expanded?, children? }>` | — | The hierarchy to render. Leave it out to compose the parts yourself. |
| `label` | `string` | — | The tree's name for screen readers. |
| `labelledby` | `string` | — | The id of a visible heading that names the tree instead. |
| `value` | `Bindable<string \| string[]>` | — | The selected node's name, or the list of names with `multiple`. |
| `multiple` | `boolean` | `false` | Lets people select several nodes. |
| `manual` | `boolean` | `true` | Leave it on so moving focus never changes the selection; turn it off to select as focus moves. |
| `required` | `boolean` | `false` | Keeps a single-select tree from ending up with nothing selected. |
| `disabled` | `boolean` | `false` | Locks selection and expansion across the tree. |
| `size` | `xs`–`xxl` | `'sm'` | Reaches every row. |
| `color` | `primary`, `secondary`, `tertiary`, `error`, `success`, `warning`, `info` | `'primary'` | The color of selected rows. |
| `onchange` | `(event: CustomEvent<string \| string[] \| undefined>) => void` | — | The selection changed; `detail` is the whole value. |
| `className` | `string` | — | Added alongside the built-in classes, or in place of them with `overrides` enabled. |

Slots, used with `items`:

| Slot | Receives | Renders |
| --- | --- | --- |
| `item` | the entry (`name`, `label`, `children`, …) | What the row shows, in place of its label. |

Parts, used without `items`:

| Part | Props | Notes |
| --- | --- | --- |
| `TreeItem` | `name`, `label`, `expanded`, `disabled`, `ontoggle` | One node. `expanded` or a nested `TreeGroup` makes it a branch; `label` names a branch for screen readers. |
| `TreeGroup` | `label`, `labelledby` | The children of a branch, shown while the branch is open. |

Keyboard: `Tab` enters on the selected node. `Down` and `Up` move to the next and previous visible node without wrapping, `Home` and `End` jump to the first and last, `Right` opens a closed branch or steps into an open one, `Left` closes an open branch or returns to its parent, and `Enter` or `Space` selects.
