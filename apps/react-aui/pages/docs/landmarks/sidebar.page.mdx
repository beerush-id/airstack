# AUI Sidebar

A sidebar holds content that supports the document without belonging to it: related links, filters, notes, a table of contents. The sidebar compiles `complementary` onto a real `<aside>` and adds a name when a page holds more than one.

Styling is optional. Without AUI CSS the Sidebar stays a correct, operable landmark; with it, the same markup gets the AUI treatment through the full library.

:::interactive[Sidebar demo]

```tsx
import { Sidebar, Toggle } from '@airlib/react-aui';
import { $bind, mutable, setup, Snippet } from '@airlib/react';

const SidebarDemo = setup(() => {
  const state = mutable({ named: true });

  return () => (
    <div className="demo-button">
      <Toggle pressed={$bind(state, 'named')}>
        {() => (state.named ? 'Named' : 'Unnamed')}
      </Toggle>
      <div className="aui-card flex gap-md items-center justify-center p-xl">
        <Snippet>
          {() => (
            <Sidebar label={state.named ? 'On this page' : undefined}>
              <span>Parameters</span>
              <span>Usage</span>
              <span>Next steps</span>
            </Sidebar>
          )}
        </Snippet>
      </div>
    </div>
  );
}, 'SidebarDemo');
```

## Usage

```tsx
import { Sidebar } from '@airlib/react-aui';
import '@airlib/aui/components/landmarks/sidebar.css';

export const TableOfContents = () => (
  <Sidebar label="On this page">
    <span>Parameters</span>
    <span>Usage</span>
    <span>Next steps</span>
  </Sidebar>
);
```

For the full library — tokens, base defaults, every component, and the utilities — load `import '@airlib/aui';` instead. The landmark stylesheet carries no visuals; the native host supplies the semantics.

### Properties

| Prop | Type | Default | Notes |
| --- | --- | --- | --- |
| `label` | `string` | — | The name screen readers announce, compiled to `aria-label`. Omitted when absent. |
| `labelledby` | `string` | — | The ID of an element that provides the name, compiled to `aria-labelledby`. |
| `id` | `string` | — | Your hook for fragment links; the controller compiles no identifier. |
| `className` | `string` | — | Added alongside the built-in classes, or in place of them with `overrides` enabled. |
| `children` | `ReactNode` | — | Supporting content; the sidebar takes no ownership of what it holds. |
| `ref` | `Ref<HTMLElement>` | — | Access to the underlying aside element. |

Set, change, or clear `label` or `labelledby` and the projection follows. Both props compile to their `aria-*` counterparts only and never leak onto the host as plain attributes.

To make `className` replace the built-in classes, turn on `overrides` once in [Theming](/docs/theming#overrides).

Keyboard: none. The sidebar takes no tab stop and claims no keys; name each sidebar when a page holds more than one.
