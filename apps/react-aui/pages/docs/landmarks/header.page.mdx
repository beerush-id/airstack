# AUI Header

Identity, navigation, and account controls repeat at the top of every page, and a landmark is what lets a user skip them or jump straight back to them. The header compiles `banner` onto a real `<header>` and adds a name only when a document carries two.

Styling is optional. Without AUI CSS the Header stays a correct, operable landmark; with it, the same markup gets the AUI treatment through the full library.

:::interactive[Header demo]

```tsx
import { Header, Toggle } from '@airlib/react-aui';
import { $bind, mutable, setup, Snippet } from '@airlib/react';
import { GlassStage } from '@/components/GlassStage.js';

const HeaderDemo = setup(() => {
  const state = mutable({ named: true });

  return () => (
    <div className="demo-button">
      <Toggle pressed={$bind(state, 'named')}>
        {() => (state.named ? 'Named' : 'Unnamed')}
      </Toggle>
      <GlassStage>
        <div className="flex gap-md items-center justify-center">
          <Snippet>
            {() => (
              <Header label={state.named ? 'Site' : undefined}>
                <span>AirLib</span>
                <nav aria-label="Primary">
                  <a href="#docs">Docs</a>
                </nav>
              </Header>
            )}
          </Snippet>
        </div>
      </GlassStage>
    </div>
  );
}, 'HeaderDemo');
```

## Usage

```tsx
import { Header } from '@airlib/react-aui';
import '@airlib/aui/components/landmarks/header.css';

export const SiteHeader = () => (
  <Header label="Site">
    <span>AirLib</span>
  </Header>
);
```

For the full library — tokens, base defaults, every component, and the utilities — load `import '@airlib/aui';` instead. The landmark stylesheet carries no visuals; the native host supplies the semantics.

### Properties

| Prop | Type | Default | Notes |
| --- | --- | --- | --- |
| `label` | `string` | — | The name screen readers announce, compiled to `aria-label`. Omitted when absent. |
| `labelledby` | `string` | — | The ID of an element that provides the name, compiled to `aria-labelledby`. |
| `id` | `string` | — | Your hook for the skip link; the controller compiles no identifier. |
| `className` | `string` | — | Added alongside the built-in classes, or in place of them with `overrides` enabled. |
| `children` | `ReactNode` | — | Identity, navigation, and controls inside the header. |
| `ref` | `Ref<HTMLElement>` | — | Access to the underlying header element. |

Set, change, or clear `label` or `labelledby` and the projection follows. Both props compile to their `aria-*` counterparts only and never leak onto the host as plain attributes.

To make `className` replace the built-in classes, turn on `overrides` once in [Theming](/docs/theming#overrides).

Keyboard: none. The header takes no focus and claims no keys; the links and controls inside keep their own behavior.
