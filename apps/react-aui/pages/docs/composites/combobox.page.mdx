# AUI Combobox

A combobox is a field people type into to find one option in a long list — countries, airports, team members. Typing narrows the list; the value only changes when someone actually picks a match, so a half-typed name never ends up saved. **Combobox** gives you the field, the filtered popup, and the keyboard travel from one call with your options.

:::interactive[Combobox demo]

```tsx
import { Combobox, Readout } from '@airlib/react-aui';
import { $bind, mutable, setup, Snippet } from '@airlib/react';
import { DemoControl } from '@/components/DemoControl.js';
import { GlassStage } from '@/components/GlassStage.js';

const CITIES = { ams: 'Amsterdam', ber: 'Berlin', cop: 'Copenhagen', dub: 'Dublin', vil: 'Vilnius' };

const ComboboxDemo = setup(() => {
  const state = mutable({ size: 'md', color: 'primary', value: 'ams', disabled: false });

  return () => (
    <div className="demo-button">
      <DemoControl size={$bind(state, 'size')} color={$bind(state, 'color')} disabled={$bind(state, 'disabled')} />
      <GlassStage style={{ maxInlineSize: '20rem' }}>
        <div className="flex flex-col gap-md items-stretch justify-center">
          <Snippet>
            {() => (
              <Combobox
                label="Destination"
                placeholder="Type a city"
                options={CITIES}
                value={$bind(state, 'value')}
                size={state.size}
                color={state.color}
                disabled={state.disabled}
              />
            )}
          </Snippet>
        </div>
      </GlassStage>
      <Snippet>{() => <Readout label="Chosen" value={CITIES[state.value]} empty="Nothing yet" />}</Snippet>
    </div>
  );
}, 'ComboboxDemo');
```

## Usage

### Pass your options

Hand the combobox your options and bind the value. It filters by what people type, matching both the key and the label:

```tsx
import { Combobox } from '@airlib/react-aui';
import { $bind, mutable, setup } from '@airlib/react';
import '@airlib/aui/components/widgets/combobox.css';

const AIRPORTS = { ams: 'Amsterdam Schiphol', lhr: 'London Heathrow', lis: 'Lisbon Humberto Delgado' };

export const AirportPicker = setup(() => {
  const trip = mutable({ to: '' });

  return () => (
    <Combobox label="Destination" placeholder="Search airports" options={AIRPORTS} value={$bind(trip, 'to')} />
  );
}, 'AirportPicker');
```

You supply:

- `options` — a `{ key: label }` map or an array of `{ key, label }` entries.
- `value` — the chosen key, or an array with `multiple`. Typing never writes it; only picking does.
- `label` — the field's accessible name. Always give one: the field has no visible label of its own.
- `placeholder` — the hint shown while the field is empty.
- `query` — optional. Bind it when you want the typed text, for example to fetch matches from a server.

### Change what a row or the field shows

Keep `options` and supply content through a slot:

```tsx
<Combobox options={AIRPORTS} value={$bind(trip, 'to')} label="Destination">
  <Combobox.Snippet for="option">
    {(item) => (
      <span>
        <b>{item.key.toUpperCase()}</b> {item.label}
      </span>
    )}
  </Combobox.Snippet>
</Combobox>
```

- `option` receives the entry (`{ key, label }`) and renders inside that row.
- `input` receives the current value and the field's ready-made `ref`, `props`, and `className`, for when the field itself needs different markup — spread them onto your own `<input>`.

### Compose the parts

When the list comes from somewhere the combobox cannot filter for you — a server search, grouped results — compose the parts and render the matches yourself from the typed `query`:

```tsx
import { Combobox, ComboboxInput, ComboboxOption, ComboboxPanel } from '@airlib/react-aui';

<Combobox query={$bind(search, 'text')} value={$bind(trip, 'to')}>
  <ComboboxInput label="Destination" placeholder="Search airports" />
  <ComboboxPanel>
    <For each={() => search.results}>
      {(airport) => <ComboboxOption value={airport.code}>{airport.name}</ComboboxOption>}
    </For>
  </ComboboxPanel>
</Combobox>
```

## Style it once

Set `size`, `color`, and `variant` on `Combobox` and the field, the popup, and every option follow; a part's own prop still wins. The field takes `filled`, `tonal`, or `outlined`. See [Styling a composite](/docs/theming#style-a-composite-once).

## Properties

### Combobox

| Prop | Type | Default | Notes |
| --- | --- | --- | --- |
| `options` | `{ [key]: label }`, `Array<{ key, label? }>` | — | Renders the field and one option per match. |
| `value` | `Bindable<string \| string[]>` | — | The chosen key, or keys with `multiple`. |
| `query` | `Bindable<string>` | `''` | The typed text. Cleared after a choice. |
| `multiple` | `boolean` | `false` | Allows several choices; choosing keeps the popup open. |
| `label` | `string` | — | The field's accessible name. |
| `placeholder` | `string` | — | Hint while the field is empty. |
| `open` | `Bindable<boolean>` | — | Popup visibility, if you need to control it. |
| `disabled` | `boolean` | `false` | Locks typing and choosing. |
| `required` | `boolean` | `false` | A choice must stay selected. |
| `size` | `xs`–`xxl` | `'md'` | Reaches the field, popup, and options. |
| `variant` | `filled`, `tonal`, `outlined` | `'filled'` | The field's surface. |
| `color` | `primary`, `secondary`, `tertiary`, `error`, `success`, `warning`, `info` | `'primary'` | Focus, caret, and selected rows. |
| `oninput` | `(event: CustomEvent<string \| undefined>) => void` | — | As people type. |
| `onchange` | `(event: CustomEvent<string \| string[] \| undefined>) => void` | — | After a person picks. |
| `onopen` / `onclose` | `(event: CustomEvent<boolean>) => void` | — | When the popup opens or closes. |

### Parts

| Part | Props | Notes |
| --- | --- | --- |
| `ComboboxInput` | `label`, `placeholder`, `disabled`, `size`, `color`, `variant` | The field people type into. |
| `ComboboxPanel` | `size`, `color`, `children` | The popup holding the matches. |
| `ComboboxOption` | `value` (required), `disabled`, `children` | One match; its children are the row content. |

## Keyboard

Typing opens the popup and narrows it. Arrows move through the matches without choosing; `Enter` chooses. `Escape` closes the popup and keeps focus in the field; `Tab` leaves and closes it.
