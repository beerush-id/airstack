# AUI Drawer

Filters beside a results list, the detail of a row, a settings pane, a cart: content that belongs to the current page but needs more room than a popover. A drawer slides that content in from an edge, keeps the page visible behind it, and gives focus back to where it was when it closes.

It behaves like a [Dialog](/docs/composites/dialog) in every way that matters — focus moves in and stays there while it is modal, `Escape` and an outside press close it, and the element that opened it gets focus back.

:::interactive[Drawer demo]

```tsx
import { Drawer, Select, Switch } from '@airlib/react-aui';
import { $bind, mutable, setup, Snippet } from '@airlib/react';
import { DemoControl } from '@/components/DemoControl.js';
import { GlassStage } from '@/components/GlassStage.js';

const SIDES = { start: 'Start', end: 'End', top: 'Top', bottom: 'Bottom' };

const DrawerDemo = setup(() => {
  const state = mutable({ size: 'md', color: 'primary', side: 'end', saved: false });

  return () => (
    <div className="demo-button">
      <DemoControl size={$bind(state, 'size')} color={$bind(state, 'color')}>
        <Select size="sm" options={SIDES} value={$bind(state, 'side')} />
      </DemoControl>
      <GlassStage>
        <div className="flex gap-md items-center justify-center">
          <Snippet>
            {() => (
              <Drawer
                side={state.side}
                label="Filters"
                title="Filter results"
                description="Narrow the list to what you need."
                closeLabel="Done"
                size={state.size}
                color={state.color}
              >
                <label className="flex items-center justify-between gap-md">
                  Only saved items
                  <Switch checked={$bind(state, 'saved')} size={state.size} color={state.color} />
                </label>
              </Drawer>
            )}
          </Snippet>
        </div>
      </GlassStage>
    </div>
  );
}, 'DrawerDemo');
```

## Usage

### A drawer in one call

Give the drawer a `title`, a `label` for the button that opens it, a `closeLabel` for the button that closes it, and the content as children. It renders the buttons, the sheet, the heading, and a scrolling body:

```tsx
import { Drawer } from '@airlib/react-aui';
import '@airlib/aui/components/widgets/drawer.css';

<Drawer label="Cart" title="Your cart" description="3 items" closeLabel="Close cart" side="end">
  <CartItems />
</Drawer>
```

Every word on the drawer comes from you, in your users' language — leave `closeLabel` out and no close button is drawn (`Escape` and an outside press still close it).

`side` picks the edge: `end` (default), `start`, `top`, or `bottom`. `start` and `end` follow the reading direction, so a right-to-left page opens them from the opposite edge.

### Your own buttons

The `actions` slot replaces the single close button. Use `DrawerClose` for any button that should close the drawer:

```tsx
<Drawer label="Edit profile" title="Edit profile">
  <ProfileForm />
  <Drawer.Snippet for="actions">
    {() => (
      <>
        <DrawerClose>Cancel</DrawerClose>
        <Button type="submit" form="profile">Save</Button>
      </>
    )}
  </Drawer.Snippet>
</Drawer>
```

The heading and the action row stay in place while the body scrolls, so a long form never hides its Save button.

### Open it from your code

Bind `open` to open the drawer from anywhere — a row click, a keyboard shortcut — and to know when it closed. Leave `label` out when nothing on the page should open it directly:

```tsx
<Drawer title={order.number} open={$bind(ui, 'orderOpen')}>
  <OrderDetail order={order} />
</Drawer>
```

### Build it from parts

When the sheet's layout is yours — tabs inside, a sticky search, two footers — compose the parts:

```tsx
import { Drawer, DrawerClose, DrawerDescription, DrawerPanel, DrawerTitle, DrawerTrigger } from '@airlib/react-aui';

<Drawer side="start" size="lg">
  <DrawerTrigger>Menu</DrawerTrigger>
  <DrawerPanel>
    <DrawerTitle>Workspace</DrawerTitle>
    <DrawerDescription>Switch projects or open settings.</DrawerDescription>
    <WorkspaceNav />
    <DrawerClose>Close</DrawerClose>
  </DrawerPanel>
</Drawer>
```

Set `size` and `color` on `Drawer` and the trigger and buttons inside follow; a part's own prop wins. See [Theming](/docs/theming#style-a-composite-once).

### Properties

| Prop | Type | Default | Notes |
| --- | --- | --- | --- |
| `side` | `'start'`, `'end'`, `'top'`, `'bottom'` | `'end'` | The edge the sheet slides in from. |
| `open` | `Bindable<boolean>` | `false` | Whether the drawer is open. |
| `label` | `string` | — | Text of the button that opens it (simple form). |
| `title` | `string` | — | The drawer's heading; turns on the simple form. |
| `description` | `string` | — | A line under the heading. |
| `closeLabel` | `string` | — | Text of the close button; without it, no close button is drawn. |
| `modality` | `'modal'`, `'nonmodal'` | `'modal'` | A modal drawer dims the page and keeps focus inside. |
| `dismissable` | `boolean` | `true` | Whether `Escape` and an outside press close it. |
| `size`, `color`, `variant` | shared vocabulary | — | Reach the trigger and buttons inside. |
| `onopen` / `onclose` | `(event) => void` | — | Fire when the drawer opens and closes. |

Slots: `trigger` replaces the opening button's content; `actions` replaces the close button.

Parts: `DrawerTrigger`, `DrawerPanel`, `DrawerTitle`, `DrawerDescription`, `DrawerClose`.

Keyboard: `Tab` stays inside an open modal drawer; `Escape` closes it unless `dismissable` is off; closing returns focus to whatever opened it.
