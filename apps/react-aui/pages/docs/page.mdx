# React AUI

React declarations over AirLib Headless Kits, presentation from AUI native CSS. Headless Kits own behavior and accessibility; `@airlib/react-aui` declares structure and class composition; `@airlib/aui` supplies tokens and stylesheets. Components stay operable without CSS; CSS is always optional.

## Installation

```bash
npm install @airlib/react-aui @airlib/aui
```

`react`, `react-dom`, and `typescript` are peer dependencies, so your app supplies them. The AirLib packages — `@airlib/react`, `@airlib/aria`, and `@airlib/aui` — install as dependencies.

Load either the full library or individual component styles:

```tsx
import '@airlib/aui';
```

```tsx
import '@airlib/aui/components/widgets/button.css';
```

`@airlib/aui` loads the whole system: theme tokens, base defaults, every component family, and the utilities. An individual stylesheet such as `components/widgets/button.css` carries only that component's own rules, so it gives you the component's structure without the tokens and utilities the full library supplies.

## Components

### Widgets

- [Button](/docs/widgets/button) — Action trigger with safe form defaults, six sizes, five variants, and seven colors.
- [Toggle](/docs/widgets/toggle) — Two-state button with pressed announcement, six sizes, and seven colors.
- [Link](/docs/widgets/link) — Destination trigger on a real anchor with disabled cancellation and the current-page mark.
- [Switch](/docs/widgets/switch) — Binary on/off control with a track and thumb, six sizes, and seven colors.
- [Divider](/docs/widgets/divider) — Structural boundary on a real element with the separator role, an opt-in rule color, and horizontal or vertical axes.
- [Image](/docs/widgets/image) — Image loading coordinator with an accessible fallback, a read-only lifecycle status, and a decorative mode that leaves the accessibility tree.
- [Checkbox](/docs/widgets/checkbox) — Yes-no box with an undecided state on a native input, named by its wrapping label.
- [Checkbox Group](/docs/widgets/checkbox-group) — One committed set of checked values across many boxes, each toggling on its own.

### Composites

- [Select](/docs/widgets/select) — Collapsible option list with trigger, popup panel, and options, in single or multiple mode.

### Landmarks

- [Header](/docs/landmarks/header) — Document header on a real header element with the banner role and an opt-in accessible name.
- [Main](/docs/landmarks/main) — Primary content on a real main element with the main role and an opt-in accessible name.
- [Footer](/docs/landmarks/footer) — Document footer on a real footer element with the contentinfo role and an opt-in accessible name.
- [Section](/docs/landmarks/section) — Named page region on a real section element with the region role published only while named.
- [Sidebar](/docs/landmarks/sidebar) — Supporting content on a real aside element with the complementary role and an opt-in accessible name.

More groups and components will appear here as their slices land.
